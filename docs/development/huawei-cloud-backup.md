# 华为账号与云空间备份

接入范围：普通华为账号客户端连接 + 云空间文件备份／恢复。保留本地账本为日常写入源，不实现结构化多端账目合并，不接入 Cloud Foundation Kit 或自建账号服务器。

## 准备与入口

- 设置页“华为账号与云备份”进入独立 HDS 子页面。
- 复用 entry/module.json5 已有 client_id 和 INTERNET 权限，未修改签名配置；开发者中心的应用 Client ID、包名、调试／发布证书指纹仍需实际核对。
- 经用户确认，在 AppScope/app.json5 声明 cloudFileSyncEnabled=true。不启用 cloudStructuredDataSyncEnabled。
- 普通账号登录使用 Account Kit 的 LoginWithHuaweiIDButton、LoginType.ID，不获取手机号。账号标识和头像昵称缓存在本地 Preferences；不保存授权码和令牌，不向日志输出账号标识。进程重启后通过 getHuaweiIDState 校验账号仍为 AUTHORIZED 才恢复连接，明确失效时清除缓存。这是客户端与系统账号的关联，不代表应用服务端账号认证。
- 未新增外部依赖、服务器、付费 API 或数据库迁移。

## 运行环境与系统设置

参照官方适配指南：HarmonyOS 6.0.0.115 及以上、云空间 6.0.0.300 及以上，API 21 Release 及以上；代码额外检查 SDK 版本与云文件系统能力。不支持时保留本地／WebDAV 备份。

用户在系统设置 → 华为账号 → 云空间中开启本应用同步。页面提供系统云空间链接，无法拉起时显示手动操作路径。开关未打开、账号异常、网络、电量或空间不足时，按系统返回结果显示相应提示。

## 备份与恢复

1. 登录和打开页面不生成备份；用户点击“立即备份”并确认上传完整账本、账户、备注和附件后，才生成现有 .xqbackup 包。
2. 在本地 cacheDir 完整生成包，确认当前系统账号匹配后，复制至 /data/storage/el2/cloud/xiaoqiao-backups/<OpenID的SHA256>/ 下的临时文件，再重命名为唯一的 backup-时间戳-UUID.xqbackup。临时文件不进入可恢复列表。
3. 沿用完整包 32 MiB 限制，备份包未另设密码，不将摘要命名空间当作加密措施。备份按时间保留为独立文件，不自动覆盖或清理旧云记录。
4. FileSync.on('progress') 监听系统状态，FileSync.start() 返回只表示请求被接受；页面区分“已写入云目录／已请求同步”与“系统同步已完成”。列表是当前设备云目录视图，不证明每份文件都已完成服务器上传。最近同步时间也是系统返回值。
5. 恢复时先通过 CloudFileCache 缓存文件（最长等待 120 秒），复制到本地 cacheDir，交由已有 backup.prepare 做包、数据库和资源校验。展示账本、账目、账户摘要；再次确认覆盖并核对账号后才调用 backup.restore。
6. 沿用现有恢复前副本、回滚及恢复异常处理；恢复后刷新首页和账户读取。账号变化后清理页面预览，不读取另一账号命名空间。断开应用连接不会关闭系统同步开关或删除云端文件。
7. 页面操作期间通过原有 backupBusy 阻止跳转和其它写入；离开页面解除同步监听，丢弃未执行的恢复预览；不停止用户已授权的系统后台同步。

应用的对外隐私声明发布前应同步说明备份范围、华为云空间存储目的、系统开关、用户删除云数据和导出方式。本轮只更新仓库内开发说明，未发布隐私声明。

## 本轮验证边界

仅核对本地 SDK 的账号按钮、getHuaweiIDState、FileSync、CloudFileCache、文件读写接口及仓库调用关系，执行 git diff --check。按用户要求未运行构建、测试、模拟器或真机；没有实际登录、上传、下载或恢复账本，也未在开发者后台开通或部署服务。

待手动确认：登录与取消、Client ID／签名匹配、系统开关可见、同账号两设备上传下载、后台同步状态、离线／空间不足、账号切换、恢复预览取消、恢复与回滚及旧备份保留。费用和正式上线条件以华为后台及最新政策为准，本轮未验证开发者账号实际服务开通状态。


编译反馈修复：HuaweiAccountConnection 静态方法通过类名访问 openID 与 disconnect，避免 ArkTS 的 arkts-no-standalone-this 错误。已静态检查新增云备份类的静态方法，无同类 this 用法；未重新运行构建，待用户手动编译确认。


我的页资料展示：首次通过华为原生按钮连接后申请 openid/profile 授权，取消资料授权不撤销登录；重新登录时可再次授权。通过本地 Preferences 保存头像 HTTPS 地址与昵称（不下载图片），响应 state 及 OpenID 必须与当前账号匹配。断开或切换账号清空资料，不获取手机号。我的页头像加载失败时显示默认图标；统计口径见[我的页](my-page.md)。

账号子页面移除顶部连接卡片，底部提供“退出登录”：撤销本应用华为账号授权后清除本地缓存与内存连接，关闭同步监听并返回；不退出设备系统华为账号、不删除云端文件。未登录从备份入口进入时仍显示原生登录按钮。

退出登录授权规则：用户已选择退出时撤销授权。HuaweiCloudPage 调用 Account Kit createCancelAuthorizationRequest，使用随机 state 校验响应；成功后清除本地缓存与内存连接、关闭同步监听并返回。撤销失败时提示重试，不提前清除本地连接；下次登录由华为系统重新请求授权。不退出设备系统账号，不删除账本或备份。未运行实际撤销授权或设备验证。

重装后云目录诊断：连接流程区分账号校验、云同步初始化、同步状态读取、备份目录读取；失败显示步骤与数字错误码，不输出原始错误消息、账号或目录。备份记录未成功读取时不显示“暂无备份”；同步完成后重新读取目录。实际重装后错误原因需依据设备返回错误码确认，静态检查不能代替设备验证。

云目录访问错误 13900012：云根目录改由 Context.cloudFileDir 提供，不再硬编码；仍保留原账号隔离子目录与文件名，不执行数据迁移。此码表示文件系统拒绝访问，不等同 Account Kit 登录授权失败；提示用户安装／重装后检查系统云空间中的本应用同步开关。官方指南仍将 /data/storage/el2/cloud 作为沙箱目录，因此仅改用 Context 不足以证明设备权限问题已解决，需设备验证。参考：https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/app-cloud-sync-filesync/ 。

同步开关已开启仍返回 13900012 时，不再推断开关未开。列表读取移除 access 前置检查，直接 listFile；只有 13900002（目录不存在）作为空列表处理，其他异常保留。列举备份子目录被拒时仅对系统云根目录做只读列举探测，区分根目录列举、账号目录列举和文件 lstat 失败。不创建／修改目录、不扫描其他账号备份，不在界面输出路径或文件名。此修改需设备重试以确定是 access 前置检查失败还是持续存在的目录访问异常。

重装后同步启动顺序：进入云备份页注册监听后主动请求同步；手动刷新也先请求同步再读取目录，避免 list 失败使 FileSync.start 永远不执行。start 返回仅表示受理，不能认定元数据已就绪；仍由完成事件重新读取列表，不创建占位备份、不自动覆盖数据。用户设备已观察到立即备份后新旧记录与旧备份预览可读取，此证据不能确定是目录创建还是系统初始化触发了恢复。本次顺序调整待设备验证。

云备份按条删除：每条记录右侧三点菜单提供“查看并恢复”和“删除备份”。删除前确认日期、大小及跨设备同步与不可撤销影响；确认前后校验账号一致性。仅允许当前账号目录下符合 backup 文件名规则的普通文件，拒绝符号链接，不递归删除。存在恢复预览、处理中或恢复异常时禁用菜单；删除不依赖本地账本 ready 状态。unlink 成功后移除本地列表记录并请求同步，提示等待云端同步，不把本地删除当作云端删除完成。同步请求失败保留“已删除、同步未完成”事实。未执行真实文件删除或设备验证。
