# 收支分类管理

收支分类是账目明细维度，与预算分类、标签相互独立。设置页提供“管理收支分类”入口。

## 能力

- 支出与收入分类分开展示。
- 新增根分类或任意层级子分类；允许直接使用父分类记账，不强制细分。
- 编辑名称、图标和父分类，移动后追加到目标父级的同级末尾。
- 使用同级上移、下移调整顺序，列表采用深度优先顺序展示。
- 归档与恢复。归档父分类前必须先归档其启用中的子分类。
- 至少保留一个启用中的收入分类和一个启用中的支出分类。
- 已归档分类继续用于历史账目展示；编辑旧账目时仍可保留原分类。

数据库沿用 `categories.parent_id` 单一树结构，`category_closure` 递归视图用于统计和循环检查。名称在相同账本、类型、父分类下唯一，分类书籍归属和收支类型不可修改。

自定义图片图标仍需后续接入系统文件选择器；本轮使用现有内置彩色分类图标。

## 验证

`Categories` 原生测试覆盖三级分类、同级重名拒绝、循环移动拒绝、改名换图标、同级排序、父分类归档保护、逐级归档与恢复。`CategoryUI` 覆盖设置页入口、分类树和新增分类 Sheet。完整回归继续覆盖原记账与预算路径。

最终验证：分类业务测试 1/1、分类 UI 1/1、完整 API 26 原生回归 50/50 通过；真机截图确认父分类和子分类的层级缩进、同级排序及管理操作布局。
