# 收支分类管理

收支分类是账目明细维度，与预算分类、标签相互独立。设置页提供“管理收支分类”入口。

## 能力

- 支出与收入分类分开展示。
- 新增根分类或任意层级子分类；允许直接使用父分类记账，不强制细分。
- 编辑名称、图标和父分类，移动后追加到目标父级的同级末尾。
- 首屏只显示一级分类，点击名称区域进入子分类列表，逐层浏览；标题返回、路径返回和系统返回优先回到上一级。
- 使用中分类支持同级拖拽排序，不再显示上移、下移；已归档视图不参与排序，保留通往归档子分类的父级入口。
- 归档与恢复。归档父分类前必须先归档其启用中的子分类。
- 至少保留一个启用中的收入分类和一个启用中的支出分类。
- 已归档分类继续用于历史账目展示；编辑旧账目时仍可保留原分类。

数据库沿用 `categories.parent_id` 单一树结构，`category_closure` 递归视图用于统计和循环检查。名称在相同账本、类型、父分类下唯一，分类书籍归属和收支类型不可修改。

自定义图片图标仍需后续接入系统文件选择器；本轮使用现有内置彩色分类图标。

## 验证

`Categories` 原生测试覆盖三级分类、同级重名拒绝、循环移动拒绝、改名换图标、同级排序、父分类归档保护、逐级归档与恢复。`CategoryUI` 覆盖设置页入口、分类树和新增分类 Sheet。完整回归继续覆盖原记账与预算路径。

最终验证：分类业务测试 1/1、分类 UI 1/1、完整 API 26 原生回归 50/50 通过；真机截图确认父分类和子分类的层级缩进、同级排序及管理操作布局。

## 逐级浏览与拖拽排序（2026-11-14）

- 每行采用 76vp 高度，右侧编辑、归档／恢复按钮及拖动图标垂直居中；名称区域进入子分类，路径区域可返回上一级。当前层级新增默认选择当前父分类。
- 沿用 Scroll 与 HDS 标题栏绑定，通过 [ArkUI 顺序组合手势](https://developer.huawei.com/consumer/en/doc/harmonyos-references/ts-combined-gestures/) 的 LongPressGesture（300ms）与 PanGesture 实现拖拽。短划用于滚动，长按提起后显示 1.05 倍缩放与加深阴影，拖动行实时跟手，相邻行以 200ms EaseOut 平移让位；松手后 200ms 落位并收回阴影。拖动到可视区边缘时自动滚动，取消手势恢复原位。
- 拖动预览保留原布局槽位，以固定行距计算插入位置，不在每次移动时写库。拖动、落位和保存期间锁定编辑、归档、层级切换及返回，避免目标变化；离页清理定时器。
- 新增 CategoryOrderItem 与 LedgerWorkspace.reorderCategories(kind,parentId,order)。调用方提交完整的使用中同级分类 ID 和版本，单一 RdbSession.write 事务核对账本、类型、父分类、完整成员集合与版本，然后连续更新排序及版本；任一冲突整笔回滚。接口不更改父子关系，不排序归档分类，不涉及结构升级或数据迁移。旧 moveCategory 接口为已有调用保留。
- 成功后应用已提交的顺序；失败后动画恢复原显示顺序，并提供刷新入口。已有新增回传、编辑、归档保护和收入／支出分组规则保留。
