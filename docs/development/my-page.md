# 我的页

底部原“设置”页签更名为“我的”，图标改为用户轮廓，HDS 标题同步为“我的”。保留 LocalBackupPage 组件名及原有管理、导入导出、本地／WebDAV／云空间备份入口，避免改变现有备份状态流程。

## 账号区域

顶部使用 64vp 圆形头像、22fp 昵称与次级说明；未登录显示默认头像、“未登录”和“点击使用华为账号登录”。未登录时点击直接调用 Account Kit 发起华为账号登录，校验返回 state 后连接账号，并请求可选的头像昵称授权；登录期间禁用重复点击并显示“正在登录…”，取消或失败以 Toast 提示，不跳转子页面。已登录时点击仍进入华为账号与云备份页。已连接后显示授权头像昵称；未取得 profile 授权时使用默认头像与“华为账号用户”，图片加载失败同样回退默认头像。

Account Kit 的 profile 授权只用于展示资料；使用 state 和 OpenID 进行账号一致性检查，取消资料授权不影响账号连接或云备份。首次原生登录后可弹出资料授权；已有连接恢复时不强制弹窗，重新登录时可再次请求头像昵称授权。账号标识、头像地址与昵称保存在本地 Preferences（huawei_account_connection），不保存授权码、令牌或客户端密钥，也不记录用户标识到日志。启动时读取缓存，但必须通过 getHuaweiIDState 校验 AUTHORIZED 才恢复已登录展示；暂时校验失败不删除缓存，明确失效或账号变更时清除。退出登录先撤销本应用华为账号授权，再清除内存及本地缓存，关闭本应用同步监听并返回我的页，不退出系统华为账号、不删除云备份。账号与云备份子页面移除顶部账号卡片，底部保留退出登录；从备份入口未登录进入时仍可使用原生登录按钮。头像缓存为 HTTPS 地址，未下载为本地图片。

## 三列汇总

- 记账天数：所有账本第一笔有效账目日期到本机今天的自然天数，包含首日，不是实际有记账的日期数量；最少显示 1 天，无账目或只有未来账目时也显示 1 天。以账目存储的本地日期和当天本地日期计算 UTC 日期差，避免夏令时导致 23／25 小时一天的偏差。
- 记账笔数：v_posted_transactions 中 expense／income／transfer 的记录总数，涵盖所有账本；已删除、未入账和未提交导入批次不计入，报销／退款到账不重复计数，转账一笔记一笔。
- 净资产：直接复用资产页 AccountOverview.netMinor，保留纳入净资产账户的既有资产／负债口径，不取当前月结余。
- 新增 LedgerWorkspace.usageSummary 只读查询和 LedgerUsageSummary（firstEntryDate、entryCount）类型，不涉及数据库结构或迁移。页面激活、账目刷新和从账号页返回时更新；汇总在首页账本加载、保存、恢复、删除及进入我的页时由父页面统一读取后传入；初次读取期间天数／笔数分别显示 1／0 并提示正在读取，失败显示明确重试入口，不再长期显示横线。
- 数字为 22fp DIN，标签为 12fp 次级文字，等宽三列。金额用两位小数与千位分隔，长金额自动缩小。

## 验证边界

已核对 Account Kit 官方授权文档及本地 SDK 返回字段，静态检查只读汇总口径、空数据、跨年／夏令时日期差、账号退出与图片失败回退，执行 git diff --check。按用户要求未运行构建、自动化测试、模拟器或真机，实际登录授权、头像加载、自然天数和大金额布局需手动确认。

官方参考：[华为账号认证与 profile 授权](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/account-api-authentication/)。


修复汇总横线：移除依赖 LocalBackupPage 激活／ready 状态触发的子页面只读查询，Index 统一加载并响应式传入汇总数据；读数失败单独记录错误并允许重试，不影响账本和账户读取。自然天数最低为 1；记账笔数无账目为 0。按用户要求未构建或运行测试，git diff --check 通过，实际数据加载待用户手动确认。


## 我的页快捷入口

个人汇总下使用白色圆角容器，四列两行，顺序为：账本管理、资产账户、分类设置、预算分类／修改预算、图表统计、账单明细、自定义标签。对应资源由用户提供的 mine-icon-*.png 原样重命名为 mine_icon_*.png（所有连字符转下划线），不改像素内容。

原图 120×120，含发光留白；采用 40vp 图片框保留约 24–28vp 主体视觉尺寸，文字 13fp，每格高度 92vp，整格可点击。图标不重新染色。导入导出、云备份、本地备份和 WebDAV 入口继续保留在后方。

账本管理调用已有账本 Sheet；将唯一 showSelection Sheet 绑定从首页导航移到公共 HdsTabs 容器，支持在“我的”页打开及返回原页面。资产账户、图表统计、账单明细分别切换到已有资产／统计／账目页签；分类、预算分类、自定义标签进入已有管理页，修改预算进入已有月预算页面，保留当前账本和周期。

静态核对八个入口的资源名和回调，git diff --check 通过；按用户要求未构建或运行界面测试，实际图标尺寸、Sheet 遮罩与返回、入口点击效果待手动确认。


## 分组 Cell 与备份子页面

八个快捷入口下方仅展示“导入与导出”“备份与恢复”两行 Cell。使用现有 HdsListItemCard 原生 PrefixIcon、textItem.primaryText 与 SuffixArrow 槽位，系统规格图标与单行主标题采用标准 Cell 排列；每行 60vp，合并为一个 20vp 圆角卡片，分割线从标题处缩进。

“我的”页不再展开本地备份操作、WebDAV 面板、云备份按钮或恢复预览。“备份与恢复”进入 BackupRestorePage，集中保留本地导出／导入、恢复前副本、WebDAV、华为账号与云备份入口、预览确认及反馈；账户头部仍可进入账号页。云备份页关闭后返回备份子页，从子页返回我的页。备份忙碌时继续阻止返回和其它操作，校验、确认、恢复与回滚逻辑沿用原实现；离开备份页丢弃未执行的恢复预览。

本轮修改 LocalBackupPage、Index，新增 BackupRestorePage，未修改数据库和备份包格式。git diff --check 通过；按用户要求未构建或运行界面测试，需手动确认两条 Cell 点击、子页返回、WebDAV 预览及恢复流程。


Cell 布局反馈修复：原 PrefixCustomBuilder 同时放置图标与标题、且未提供 textItem，导致原生文本区布局不匹配。改为 PrefixIcon 只负责图标，textItem.primaryText 提供完整标题并明确左对齐，SuffixArrow 提供右箭头；删除两个自定义区域 Builder，保留行高、分组圆角和点击行为。核对本地 SDK 选项声明，git diff --check 通过；未构建或设备复验。


Cell 第二次布局修正：用户截图显示使用原生槽位后标题仍未显示，继续排查内部宽度与通用属性冲突。按[HdsListItemCard 官方属性说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ui-design-hdslistitemcard/)，移除组件外层 width／enabled／onClick，统一通过 cardWidth／enable／onClick 选项设置。cardWidth 不再传百分比，改为分组容器 onAreaChange 实测 vp 宽度，取得有效宽度后才创建卡片，保留首帧高度占位；原生标题、图标和箭头配置不变。git diff --check 通过，实际布局仍待用户设备确认，未执行构建或界面测试。


我的页尺寸收紧：按用户要求仅调整大小。头像直径 64→56vp（占位图标 32→28vp），昵称和汇总数字 22→20fp；快捷图标框 40→36vp，标签 13→12fp，每格高 92→76vp；Cell 行高 60→52vp，图标用 SMALL_ICON，主标题 TextModifier 设置 14fp，首帧占位同步为两行共 104vp。原布局、间距、颜色、字重和交互保持不变。SDK 注释对 TextModifier 支持范围有限定，实际 Cell 标题字号是否生效需设备确认；本轮未构建或界面测试，git diff --check 通过。


Cell 最终改为自定义实现：按用户要求移除我的页两行 Cell 的 HdsListItemCard、原生前后槽位、TextModifier 和实测宽度状态。使用 Button 包裹 Row，整行 52vp，左右内边距 16vp；图标 20vp，标题 14fp 常规字重并占据剩余宽度，右箭头 16vp，元素间距 12vp，垂直居中。两行共用原 20vp 圆角卡片，分割线从标题起点 48vp 缩进。保留点击反馈、禁用状态、无障碍名称与跳转；头像和快捷网格不变。git diff --check 通过，按用户要求未构建或运行界面测试。此节替代上文 HDS Cell 方案。


## 头像与汇总卡片背景

头像、登录占位／昵称及三项汇总合成一张圆角卡片，内边距 20vp、圆角 20vp，沿用已有头像和文字尺寸。普通版及未登录使用银灰至深灰渐变，付费版使用金棕至深色渐变，两者有低对比扇形细线纹理；只参考用户提供图片的背景风格，不包含其中的文字、商标、服务图标或钻石装饰。

新增手写矢量资源 my_profile_standard_bg.svg、my_profile_paid_bg.svg，以背景图片 Cover 填充，卡片统一使用浅色正文与次级说明，适配浅／深页面背景。LocalBackupPage.paidEdition 为默认 false 的纯视觉预留参数；只有已连接华为账号且参数为 true 时显示金色卡片。未登录始终使用普通背景，无购买入口、不校验真实会员资格、不改变数据与功能权限，后续由支付／权益模块提供状态。

git diff --check 通过并静态核对两张 SVG 结构；按用户要求未构建或设备测试，实际背景比例、纹理、头像与文字可读性仍需手动确认。

退出登录授权规则：用户已选择退出时撤销授权。HuaweiCloudPage 调用 Account Kit createCancelAuthorizationRequest，使用随机 state 校验响应；成功后清除本地缓存与内存连接、关闭同步监听并返回。撤销失败时提示重试，不提前清除本地连接；下次登录由华为系统重新请求授权。不退出设备系统账号，不删除账本或备份。未运行实际撤销授权或设备验证。

“我的”页新增“预付款与核销”入口，位于导入导出上方；口径、V8 升级与操作说明见 [预付款与核销](prepaid.md)。

预付款主要从“记一笔 → 支出”的“预付款／待核销”开关直接录入；我的页入口用于后续核销、退款与项目管理，首页资产记录可直接进入项目，见 [预付款说明](prepaid.md)。

预付款管理入口已从“我的”页移至账目页概览卡片下方。按当前账本全部预付款项目计数（含已结清、不受月份筛选影响）；项目数为零时隐藏。入口展示总笔数，并在有余额的项目存在时显示待核销数量，点击打开项目管理。首次创建仍在支出记一笔开启预付款。
