# 我的页

底部原“设置”页签更名为“我的”，图标改为用户轮廓，HDS 标题同步为“我的”。保留 LocalBackupPage 组件名及原有管理、导入导出、本地／WebDAV／云空间备份入口，避免改变现有备份状态流程。

## 账号区域

顶部使用 64vp 圆形头像、22fp 昵称与次级说明；未登录显示默认头像、“未登录”和“点击使用华为账号登录”。未登录时点击直接调用 Account Kit 发起华为账号登录，校验返回 state 后连接账号，并请求可选的头像昵称授权；登录期间禁用重复点击并显示“正在登录…”，取消或失败以 Toast 提示，不跳转子页面。已登录时点击仍进入华为账号与云备份页。已连接后显示授权头像昵称；未取得 profile 授权时使用默认头像与“华为账号用户”，图片加载失败同样回退默认头像。

Account Kit 的 profile 授权只用于展示资料；使用 state 和 OpenID 进行账号一致性检查，取消资料授权不影响账号连接或云备份。首次原生登录后可弹出资料授权；已有连接恢复时不强制弹窗，重新登录时可再次请求头像昵称授权。账号标识、头像地址与昵称保存在本地 Preferences（huawei_account_connection），不保存授权码、令牌或客户端密钥，也不记录用户标识到日志。启动时读取缓存，但必须通过 getHuaweiIDState 校验 AUTHORIZED 才恢复已登录展示；暂时校验失败不删除缓存，明确失效或账号变更时清除。退出登录先撤销本应用华为账号授权，再清除内存及本地缓存，关闭本应用同步监听并返回我的页，不退出系统华为账号、不删除云备份。账号与云备份子页面移除顶部账号卡片，底部保留退出登录；从备份入口未登录进入时仍可使用原生登录按钮。头像缓存为 HTTPS 地址，未下载为本地图片。

## 三列汇总

- 记账天数：所有账本第一笔有效账目日期到本机今天的自然天数，包含首日，不是实际有记账的日期数量；最少显示 1 天，无账目或只有未来账目时也显示 1 天。以账目存储的本地日期和当天本地日期计算 UTC 日期差，避免夏令时导致 23／25 小时一天的偏差。
- 记账笔数：v_posted_transactions 中 expense／income／transfer 的记录总数，涵盖所有账本；已删除、未入账和未提交导入批次不计入，报销／退款到账不重复计数，转账一笔记一笔。
- 净资产：直接复用资产页 AccountOverview.netMinor，保留纳入净资产账户的既有资产／负债口径，不取当前月结余。
- 新增 LedgerWorkspace.usageSummary 只读查询和 LedgerUsageSummary（firstEntryDate、entryCount）类型，不涉及数据库结构或迁移。页面激活、账目刷新和从账号页返回时更新；汇总在首页账本加载、保存、恢复、删除及进入我的页时由父页面统一读取后传入；初次读取期间天数／笔数分别显示 1／0 并提示正在读取，失败显示明确重试入口，不再长期显示横线。
- 数字为 22fp DIN，标签为 12fp 次级文字，等宽三列。金额用两位小数与千位分隔，长金额自动缩小。

本轮修改 LocalBackupPage、Index，新增 BackupRestorePage，未修改数据库和备份包格式。git diff --check 通过；按用户要求未构建或运行界面测试，需手动确认两条 Cell 点击、子页返回、WebDAV 预览及恢复流程。

## 头像与汇总卡片背景

头像、登录占位／昵称及三项汇总合成一张圆角卡片，内边距 20vp、圆角 20vp，沿用已有头像和文字尺寸。普通版及未登录使用银灰至深灰渐变，付费版使用金棕至深色渐变，两者有低对比扇形细线纹理；只参考用户提供图片的背景风格，不包含其中的文字、商标、服务图标或钻石装饰。

新增手写矢量资源 my_profile_standard_bg.svg、my_profile_paid_bg.svg，以背景图片 Cover 填充，卡片统一使用浅色正文与次级说明，适配浅／深页面背景。LocalBackupPage.paidEdition 为默认 false 的纯视觉预留参数；只有已连接华为账号且参数为 true 时显示金色卡片。未登录始终使用普通背景，无购买入口、不校验真实会员资格、不改变数据与功能权限，后续由支付／权益模块提供状态。

git diff --check 通过并静态核对两张 SVG 结构；按用户要求未构建或设备测试，实际背景比例、纹理、头像与文字可读性仍需手动确认。

退出登录授权规则：用户已选择退出时撤销授权。HuaweiCloudPage 调用 Account Kit createCancelAuthorizationRequest，使用随机 state 校验响应；成功后清除本地缓存与内存连接、关闭同步监听并返回。撤销失败时提示重试，不提前清除本地连接；下次登录由华为系统重新请求授权。不退出设备系统账号，不删除账本或备份。未运行实际撤销授权或设备验证。

“我的”页新增“预付款与核销”入口，位于导入导出上方；口径、V8 升级与操作说明见 [预付款与核销](prepaid.md)。

预付款主要从“记一笔 → 支出”的“预付款／待核销”开关直接录入；我的页入口用于后续核销、退款与项目管理，首页资产记录可直接进入项目，见 [预付款说明](prepaid.md)。

预付款管理入口已从“我的”页移至账目页概览卡片下方。按当前账本全部预付款项目计数（含已结清、不受月份筛选影响）；项目数为零时隐藏。入口展示总笔数，并在有余额的项目存在时显示待核销数量，点击打开项目管理。首次创建仍在支出记一笔开启预付款。

“账单明细”快捷入口打开独立 BillDetailsPage，不再切回账目 Tab。页面按月读取当前账本，支持月份切换、全部/支出/收入筛选、分类/备注/账户/标签关键词搜索，按日期分组并展示当日筛选结果合计。普通账目打开已有详情，返回保留明细页状态；预付款记录进入对应项目。


## 账单日历

账单明细顶部提供周一开始、完整五/六周的月历。首尾补齐相邻月份日期，降低透明度，仅显示公历日号；点击补位日期切换月份。当前月每日最多两行金额，收入绿色在上、支出橙色在下，不加收支文字、币种符号或千位分隔符，不显示零金额。金额按账本折算口径汇总，预付款原始流转不计收支；核销、退款报销等沿用现有账单日汇总规则。

金额先去掉末尾零，再以实际格宽和最小 9fp 字号测量；超宽使用万/亿紧凑格式并递减小数位，显示字号为 9–11fp。紧凑格式仅作概览，完整精确金额仍在下方当日汇总和账目行显示，不对存储金额进行取整。无收支显示常用节日，其他日期显示系统农历；农历初一显示月份名称。节日仅是名称，不代表法定放假或调休：首版包含固定公历节日和常用农历节日，暂无节气与年度班休数据。

系统农历使用 LocalizationKit 的 i18n.getCalendar('zh-Hans-CN', 'chinese')，读取 month/date/is_leap_month，避免闰月误标传统节日；失败时保留公历节日或空副标题，不影响查看账单。无新增依赖、权限或网络请求。

进入页面默认打开当前自然月，日期不选中，显示整月账单；左右切换月份也默认显示该月整月，不自动选中 1 日。点击日期筛选下方列表，再次点击已选日期取消选择并恢复整月列表；搜索/收支筛选只影响列表，日历始终反映当前月全部账目的日收支。数据读取失败时显示重试，不显示陈旧金额。

手动验证项：周一/周日起始月份、闰年二月、六周月份和跨年补位；同日双向收支/仅收/仅支/无收支；农历初一、春节/端午/中秋及闰月；大金额和系统大字体；点击日期、再次点击取消、搜索及返回详情后的状态保留。未自动运行构建或设备验证。

账单明细页改为单个 List 统一滚动：月份、完整月历、搜索和筛选构成首个 ListItem，日期分组明细紧随其后；顶部区域不再固定挤占列表高度。HDS 标题栏继续绑定同一个 Scroller，保持返回按钮与沉浸滚动效果。

日历下方不再单独展示选中日期/整月控制行，日期范围由日历选中态表示；重复点击选中日期恢复整月，其他筛选保持。

账单明细搜索使用原生 Search，左侧搜索图标、44vp 高度与胶囊圆角，提示为“搜索备注、收支分类、账户或标签”；背景继续使用 xq_app_surface_card，保留浅深色适配。


## 共用账单搜索页

首页搜索图标与账单明细页胶囊搜索入口统一打开 LedgerSearchPage。搜索范围为当前账本全部月份，不继承来源页的月份、单日或收支筛选。不额外展示范围/已显示笔数文案，通过只读分页接口匹配分类/备注/账户/标签，不增加数据库结构、权限或网络请求。

来源页面不再内联编辑关键词；账单明细搜索入口为可点击按钮，避免先弹键盘再跳转。搜索页 Search 显示后延迟请求焦点并允许自动弹出键盘；离开时清理焦点定时器。输入实时筛选，支持清空、无结果、读取失败重试及进入账目详情或预付款项目。查看普通账目详情时保持搜索页挂载，保留关键词和结果滚动位置；返回搜索来源页面优先退出搜索而非关闭来源页。

手动验证：两个入口进入后自动聚焦、键盘避让；输入/清空/提交；详情往返；物理返回和标题栏返回；跨月份匹配准确；输入中离开不会延迟抢焦点。未运行构建或设备测试。


跨月份搜索接口 `LedgerWorkspace.searchEntries(keyword, cursor?, pageSize=50)` 返回条目、hasMore 和 nextCursor，单页上限 100。RdbLedgerSearch 在共享只读会话内合并已发布普通账目、有效回款和预付款付款/退款，按时间、ID 降序使用游标分页。不逐月读取快照，不加载全部匹配结果；读取历史分类/账户，排除未发布、软删除和已撤销记录。关键词通过参数绑定和 instr/lower 字面子串匹配，% 与 _ 不作通配符。

预付款标签存于既有 JSON 文本，先做候选匹配，再解析元数据核验，仅允许项目名称、流水备注、分类/账户/标签命中，排除 JSON 中 ID、金额等字段误匹配。按小批候选扫描填充分页，不依赖额外 JSON SQL 扩展。结果保留原币金额、回款/预付款标记；分类其他收入与转账图标沿用统一映射。

搜索输入有 250ms 防抖及请求序号，关键词改变即作废旧结果，避免后返回的旧请求覆盖新关键词；清空立即移除结果。更多结果在列表触底时自动读取，不显示“加载更多”按钮；翻页失败保留已有结果并允许重试，页销毁取消待执行计时。提交搜索立即读取首屏。手动回归补充：跨年同关键词、50 条以上翻页、相同时间记录、特殊字符、已归档分类/账户、删除及回款/预付款撤销、快速换词和翻页失败重试。

## 流水与日历范围

账单明细默认仍为日历，且日历只支持月：完整月历、点击日期筛选、重复点击恢复整月的行为保留。切换为流水后隐藏月历，首次默认全部时间，提供「全部 / 年 / 月 / 周 / 自定义」。年/月/周初选当前自然周期，周从周一开始，左右按钮按对应周期移动；全部和自定义禁用周期移动。周、自定义标题完整显示 YYYY/MM/DD 起止日期，自定义在 Sheet 中分别选择开始、结束日期后确定，取消不改变现有范围；逆序起止按时间先后归一化，结束日包含当天。

两种视图的期间独立保留：流水范围不会改写日历月份。切换视图清除单日选择并回到列表顶部；收支筛选继续有效。流水范围、收支条件变化会清空游标重新读取，旧异步响应通过请求序号作废。搜索仍进入独立搜索页，搜索范围沿用当前账本全部月份，不继承流水范围。

新增只读 `LedgerWorkspace.flowEntries(query, cursor?)`，query 为 LedgerFlowQuery（startDate、endDateExclusive、kind），空日期边界表示不限；kind 与 LedgerKind 一致（0 全部、1 支出、2 收入）。返回 LedgerFlowPage（entries、hasMore、nextCursor、days）。RdbLedgerSearch.flow 复用搜索的三类已发布记录投影，使用参数绑定、日期范围及收支条件在分页前筛选，每页 50 笔，通过额外读取第 51 笔确定 hasMore，按发生时间与 ID 降序游标翻页。不做数据库迁移、写入或历史金额修订。

每页返回涉及日期的完整日汇总：再次查询这些日期的全部匹配记录，不应用分页游标；金额逐笔 BigInt 累加为字符串，避免浮点误差和 SQL SUM 整数溢出。转账本金、预付款原始付款/退款不计日收支，转账支出手续费计支出，退款与报销到账按既有口径冲减支出；支出/收入条件同时约束流水和日汇总。分页跨同一天时合并该日条目并更新完整合计，不重复日期标题。

流水保留分类备注标题、原币金额、预付款状态与账目详情入口。计数显示已加载数量，仍有后续页时附加 +；触底自动加载，失败保留已加载内容并提供末尾重试，最后一页完成后显示「没有更多了」。首屏空结果、首屏失败、翻页失败分别处理。
