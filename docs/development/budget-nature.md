# 分类预算

“预算分类”是月度预算的二级分配维度。总预算和分类预算同时存在：

- 总预算控制当月全部计入预算支出，包括没有预算分类的支出和转账手续费。
- 分类预算只统计所选预算分类下、`include_in_budget=1` 的支出。
- 历史账目若没有预算分类，只计入总预算，不进入任何分类额度。
- 分类额度合计不能超过总预算；降低总预算时也不能低于已分配合计。

## 数据结构

V4 迁移新增 `budget_nature_lines`，通过 `budget_id + spending_nature_id` 唯一绑定每月预算和预算分类。金额继续使用精确整数最小单位。数据库触发器同时保护插入/更新分类额度和降低总预算，避免绕过 UI 产生超额分配。

预算分类归档后，已有月份额度仍保留；后续月份可以继续为历史分类显示使用情况，但新记账不会展示该分类。

## 界面

首页预算铅笔进入“修改月预算”页面。页面包含：

- 本月总预算，继续使用共用金额键盘。
- 分类预算合计和未分配金额。
- 每个预算分类的额度、已用金额、进度和超预算状态。
- 点击分类进入单项额度编辑 Sheet。

用户口径保持：

- 详细记账分类叫“收支分类”。
- 分类预算维度叫“预算分类”。
- 分类额度管理功能叫“分类预算”。
- 标签继续负责多选交叉检索。
