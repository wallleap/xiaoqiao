## 初始化与数据边界

- 正常启动打开本地 `xiaoqiao.db`，首次创建时在同一事务内执行已评审的 82 条 SQL（外键 PRAGMA 在事务前设置）、写入 schema checksum、版本记录、人民币精度定义、默认日常账本、13 个一级分类及 5 个餐饮子分类。
- 不预置交易、预算、资金账户和期初余额。首次事务失败时回滚，关闭数据库；下次可重试。对已有非空库仅核对版本/校验和，不执行建表、补种或迁移；未知结构报错并保留数据。
- LedgerDatabase 复用现有 SQL 包，表结构没有变化。LedgerWorkspace 按数据库名称复用打开中的 Promise；运行期读写使用同一个 RdbSession 串行队列。
- 默认币种是 CNY，两位精度。本次仅保存同币种人民币支出，继续调用已有 RecordExpense / ExpenseRecord / RdbLedgerRepository，不把域层校验搬进页面。完整多币种、收入和转账待后续用例接入。

## 页面与交互

- 首页新增入口和“开始记第一笔账”打开全屏记一笔，使用原生 HdsNavigation；首页悬浮 Tabs 不出现在编辑层中。
- 金额固定于顶部，右侧显示选中分类图标；两行四列分类 Swiper 随表单滚动，达到阈值时顶部覆盖一行可横滑的分类入口。
- 点击有子分类的一级项先选父分类，再打开 Sheet；关闭保留父分类，继续点击可深入分类层级。账户、日期/时间、备注单独分组。
- 加、减、等于、小数点、删除、保存位于自定义键盘。计算经 Money/BigInt 完成，无 eval、parseFloat 或浮点金额计算。优惠和实付位于键盘区域；优惠是减免额，按实付保存。优惠复用自定义金额键盘，点击优惠数字进入减免额输入，点击主金额返回；备注使用系统输入，完成后可恢复金额键盘。
- 预算、资产规则互相独立。未选账户时无账户余额变动；选择账户后按已有资产规则影响余额。说明入口解释含义。
- 每次打开表单生成一个 UUID，保存期间禁用键盘，成功后关闭；失败保留表单及相同 ID，防止不确定结果重试产生第二笔。
- 保存后刷新首页，选中所保存记录所在月份，清空收支/账户/关键词筛选；查询只显示该月份的已发布有效收支。汇总使用整数字符串转 BigInt 累加，避免 SQLite SUM 溢出或浮点丢精度。
- 数据读取错误单独显示重试入口，不回退成“没有账目”，不伪造保存成功。

## 默认月预算与修改

用户确认初始预算为 2500 元，并可修改。没有独立预算记录的月份使用 250000 分作为默认额度；用户点击首页预算右侧铅笔，在 Sheet 修改当前月份的人民币额度。首次修改插入该月预算，后续修改更新相同记录及 revision；保存后立即刷新首页。

只修改当前月份，不传播到其他月份，不批量补写已有数据库，不覆盖已保存预算，不修改交易或账户余额。复用现有 budgets 表，无表结构、版本、校验和变化。读写仍走 RdbSession 串行事务。
