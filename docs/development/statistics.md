# 统计页

2026-11-08，统计 Tab 从占位提示接入真实只读数据。页面显示当前账本的支出/收入总额、趋势、收支分类排行、标签排行和预算分类排行；点击分类或标签可打开账目明细 Sheet，再进入现有账目详情。

## 统计范围与口径

- `周`：本周一至本周日，按天展示趋势。
- `月`：当前自然月，按天展示趋势。
- `年`：当前自然年，按月展示趋势。
- `自定义`：用户选择起止日期，结束日期当天包含在范围内；超过 62 天按月聚合，否则按天聚合。
- 只读取当前账本，不跨账本汇总。
- 收入只统计 `kind='income'`，不占用预算。
- 支出统计普通支出的本位币实付金额；转账本金不计入收入或支出。
- 转账手续费在 `fee_in_expense=1` 时计入支出；只有 `fee_in_budget=1` 时才进入预算分类的“未分配”。
- 收支分类排行按一级分类汇总，子分类金额归入其最高一级父分类。
- 预算分类排行只统计 `include_in_budget=1` 的普通支出；没有预算分类的历史支出和计入预算的转账手续费归入“未分配”。
- 标签排行按账目实际支出/收入金额统计；一条多标签账目会在每个标签分别计入，因此各标签金额之和可能大于总额。
- 已软删除账目、未提交导入批次和未发布交易不会被读取。

## 数据接口

`RdbStatisticsRepository` 在现有 `RdbSession` 读队列中执行只读查询，不建表、不迁移、不改账务记录。`LedgerWorkspace` 暴露两个方法：

- `statistics(startDate, endDateExclusive, kind, unit)`：返回总额、趋势桶、收支分类汇总和预算分类汇总。
- `statisticsEntries(startDate, endDateExclusive, kind, categoryKey)`：返回某一级分类下的账目明细，用于 Sheet 下钻。

金额在明细层用 `bigint` 汇总，写入 DTO 时转成十进制字符串，避免跨过 JavaScript 安全整数范围。分类汇总在内存中折叠父级路径，日期范围使用本地账单日期字段 `occurred_local_date`。

## 界面

- `StatisticsPage` 使用 `HdsNavigation`，沿用浅灰页面、纯白无描边卡片和品牌橙红。
- 标题栏右侧使用 `ChipGroup` 切换周／月／年／自定义，采用原收支切换的品牌色胶囊样式；正文取消收支与时间切换区，直接显示周期导航及合并收支统计。
- 统计 Sheet 复用 API 26 的 `THICK` 沉浸材质，API 24/25 回退为实色卡片。
- 趋势图不显示零值散点；月/日视图只标注起、中、止日期，年视图只标注起、中、止月份。
- 分类排行显示所属一级分类、占比、金额及下钻入口。
- 标签排行显示标签、笔数、占比、金额及下钻入口。
- 平板等宽屏下正文限制为 720vp，避免卡片被无限拉宽。
