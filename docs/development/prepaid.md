# 预付款与核销

## 本轮范围

用户确认金额型项目、追加付款、部分/全额核销、剩余款退款和应用内到期提醒，并单独确认 V8 升级前备份、事务迁移、保持旧账金额不变。本轮不操作设备数据库，不运行构建、自动化测试或部署，不提交 Git。

主要录入入口：“记一笔 → 支出 → 预付款／待核销”开关。新记支出时开启后，金额、付款账户、商户、备注与原图直接保存为预付款及首次付款；项目名称可选，分类和预算作为后续核销预设。管理入口仍为“我的”页下方“预付款与核销”。资产页显示纳入净资产的预付款历史成本。列表分待核销/已结清/全部，详情展示原币余额、预付/核销/退款累计、商户、到期日、项目备注及按顺序排列的流水。

第一版不含次数课程、自动按月分摊、系统通知、自动到期扣款或自动清零；押金可建立金额项目并退款，但尚无单独押金类型。提醒为到期前七天、当天和过期时显示在项目卡片中，打开页面/刷新时计算。

## 金额口径

- 预付：扣付款账户实际金额，增加预付款资产；不生成普通支出、不占预算。
- 追加付款：同一项目增加新批次，历史批次不重新计价。
- 核销：原币可用余额减少，按历史付款成本生成人民币关联支出；该支出无账户扣款，不重复扣钱。可选择支出分类、预算分类、计入预算及日期。零成本的小额尾差仅记录项目核销流水，不创建零金额账单。
- 退款：原币余额减少，到账账户增加实际到账金额；返还原成本不作为普通收入。实际到账折合人民币与释放成本不同，差额生成独立人民币收入/支出，界面明确提供两类差额分类；差额不计预算。
- 剩余 = 有效预付 − 有效核销 − 有效退款；两类处理不能超过可用余额。
- 项目按历史成本纳入净资产，可在项目元数据中关闭计入。账户自身计入净资产开关仍按原规则生效。预付款不是外币现金，不随着日常汇率波动重估。

付款、核销和退款保留原币金额。跨币种付款/到账复用 ECB 公开参考汇率与手动汇率；同币种账户结算金额必须等于本次原币金额。账本成本按实际账户金额折算人民币：人民币账户直接取实际金额，外币账户通过所填两组交叉报价折算。报价仅作为参考，不自动改历史成本。

FIFO 采用不可变的付款流水 sequence_no；部分使用按该批次剩余成本/剩余原币分配，最后一次用尽批次时释放精确剩余成本。所有金融计算使用 BigInt/现有 Money 和 ExchangeRate，写库前校验安全整数范围。整个项目累计原币预付及累计人民币成本控制在单项目安全范围内，避免派生 SUM 溢出。

## 流水一致性与撤销

项目、付款账户现金变化、FIFO 分配和关联账目在 RdbSession 的同一事务发布。每次操作要求项目 expectedRevision 匹配，使用独立事件 ID，避免旧页面并发覆盖和重复提交。

第一版流水不直接覆盖编辑，支持确认后“撤销最近一条流水”，再重新录入。撤销同时恢复项目余额、账户变动和关联账目；数据库要求逆序撤销，不允许撤销早期付款而保留后续使用。流水保留软删除历史，分配不可原地篡改。关联账单普通编辑/删除被数据库拦截，详情按钮禁用并说明应到项目处理。如果关联账单已有其他回款，原有恢复保护会阻止不完整撤销。

商户、名称、项目备注、到期日和净资产开关可编辑，项目币种和归属账本不可更改。

## 图片与备份

每条付款、核销和退款可带最多九张原图，复用已有资源保存与哈希校验流程，不压缩。表单展示缩略图，点击待保存图片可移除；流水详情保留缩略图。取消表单清理未落库资源，已落库引用不会误删。

V8 完整备份保留项目、流水、分配、关联账目和图片。备份包 schema=8；恢复 V2～V7 备份时升级候选副本后继续既有预览确认。普通 CSV 仍是收支账单导出，包含核销/退款差额的账单投影，不用于完整恢复预付款项目、付款流水和撤销历史；迁移和完整恢复应使用完整备份。

## 数据库升级

- SQL 源：docs/database/schema-v8-prepaid.sql。
- 生成命令：`python3 tools/generate-prepaid-schema.py`，仅打包 SQL 与 SHA256，不执行 SQL。
- 新增 prepaid_projects、prepaid_events、prepaid_allocations、prepaid_event_attachments，及项目余额/有效事件视图与保护触发器。
- 有效账户流水视图合并预付款付款/退款，不伪造普通收入、支出或校准。
- 初次新库依次应用到 V8；旧库沿用应用内确认入口，V7→V8 前备份为 `<数据库名>_before_prepaid_v8.db`。
- 事务内核对旧账目金额/记录数、预算及有效账户流水指纹，再检查外键与 quick_check，失败回滚；不对旧账金额重新计价。
- 备份副本保留，旧版本应用不能读取 V8；如需回退旧版本，必须恢复升级前副本。

## 验证边界与手动检查

已进行静态检查：相对模块与资源引用、方法名和 SQL 列/对象重复、生成校验和、本地 SDK 的 SheetDismiss/日期选择/小数键盘选项，以及 git diff --check。未运行构建、设备流程或真实迁移，不能据此声称运行通过。

手动重点：

1. 旧 V7 账本确认升级后，原余额、预算、账目数不变，升级前备份存在。
2. 人民币账户付款 1000：账户 −1000，预付款 +1000，净资产和月支出不变。
3. 核销 200：账户不再扣款，剩余 800，支出/预算按设置增加 200，净资产减少 200。
4. 退回 300：账户 +300，剩余 500，无普通收入；核销/退款超额被拒绝。
5. 追加不同历史汇率付款，依次部分/全额核销，最后余额与成本无尾差；跨币种退款差额记录一次。
6. 逆序撤销核销、退款和付款，关联账目、账户和项目资产一起恢复；重复/旧版本页面操作被拒绝。
7. 取消附件草稿、保存原图、完整备份恢复后项目与图片仍可读。
8. 到期前七天、当天、过期与已结清提醒；到期不自动清零。

## 记支出时直接标记

用户补充希望直接在记支出时标记，现已将其作为主要录入入口。开关只在新记支出出现，编辑已有普通支出不自动转换，以免回溯改动已结算余额与预算。预付款与待报销开关在预算分类下方共用一张卡片，互斥选择；卡片间距统一由表单的 12vp 间距控制。开启预付款后，保存按钮改为保存预付款；预算/分类为核销预设，付款时不产生普通支出。预付款计入净资产开关只控制项目资产汇总，付款账户实际变化仍按实付处理。

首次付款的原金额/优惠、地址/坐标、标签及分类/预算预设保存在事件的既有 quote_json.entry 中，无需再扩展表结构；项目管理能读取这些资料，核销表单优先采用仍有效的分类/预算预设。可核销余额按本次实付金额记录，储值赠额/次数权益不属于本轮。

首页“全部”账单展示预付款付款和退回记录及待核销/已结清标记，点击进入对应项目；资产流转不进入日/月收支汇总，也不出现在支出/收入筛选中。普通账单删除被引导到项目撤销。记账天数和笔数包含付款/退回各一次，核销生成的支出按原账目计数，不再重复计核销事件。

CSV/Excel 的收支导出继续排除未核销的付款和资产退款，保留核销/退款差额支出投影；完整项目恢复使用完整备份。相关新增联动文件：components/ExpenseEditor.ets（标记、预设与原表单付款）、domain/model/LedgerSnapshot.ets（资产记录标识）、presentation/ledger/LedgerOverview.ets（徽标与汇总排除）、data/exchange/LedgerCsvExport.ets（导出筛选）；其余接入复用上述文件索引。

此流程尚未构建或设备验证，手动检查补充：直接记支出开启预付款 → 填金额/账户/备注/图片 → 保存，首页可见待核销且月支出不增；点入核销后才出现对应支出，再检查原币余额、预算和账户不重复扣款。

直接标记预付款时必须选择付款账户；未选账户点击保存会打开账户选择 Sheet，账户行显示明确提示，预付款模式不提供“不使用账户”选项。

首次创建项目与首笔付款共用事务：项目插入成功后，将其初始版本与零余额直接交给私有流水写入方法，避免通过独立读连接重读尚未提交的项目。已有项目的后续流水仍从数据库读取并校验版本。项目或首笔付款任一失败均回滚，不拆分提交。手动回归包括直接记支出标记预付款、管理页新建项目，以及失败后确认没有空项目或账户扣款。

管理页“新增预付款”直接打开支出记一笔，默认开启预付款开关；其他记一笔入口默认仍关闭。取消或保存后返回预付款管理页，保存后刷新列表。管理入口及账目预付款记录采用原色橙金卡片图标 `icon00350`。

预付款管理入口已从“我的”页移至账目页概览卡片下方。按当前账本全部预付款项目计数（含已结清、不受月份筛选影响）；项目数为零时隐藏。入口展示总笔数，并在有余额的项目存在时显示待核销数量，点击打开项目管理。首次创建仍在支出记一笔开启预付款。

账目页尝试删除预付款流水时，使用沉浸材质浮层引导到对应项目，底部避让 104vp（含 TabBar 空间）。提供“前往”和关闭操作，黑色底板上叠加铺满卡片高度的橙色倒计时背景，橙色从右向左收缩，5 秒耗尽后自动关闭；文字、前往和关闭按钮固定显示为白色，不使用独立细进度条；重复触发重置计时，页面销毁清理定时器。其他通用提示仍使用 HDS SnackBar。

预付款 UI 层级：项目详情以核销为主色主操作，追加付款和退款为浅色次操作，编辑为文字操作，撤销最近流水单独使用警示色。表单分为金额卡片、日期/账户/分类选择卡片及备注附件卡片；编辑项目使用清晰的名称输入背景及分组，底部仅一个主色“保存修改”。金额旁“全部剩余”为轻量填充操作。该调整不修改付款、核销、退款或预算计算。

预付款表单 Sheet 的滚动区域显式顶部对齐，内部纵向从上向下排列。内容不足一屏时不垂直居中，超出时支持纵向滚动并显示自动滚动条；底部确认按钮位于滚动区域之外保持固定。

编辑项目 Sheet 标题区预留 48vp 高度及右侧 48vp 关闭按钮避让，标题下保留原有 12vp 间距，首个输入卡片从关闭按钮区域下方开始。

金额键盘核对：预付款、追加付款、核销、退款及实际账户金额统一使用 MoneyAmountField 自定义金额键盘；普通报销/退款及记一笔实际结算金额同步统一。可选实际金额支持清空后恢复按汇率计算。汇率属于高精度比率，保留独立输入，不使用货币小数位限制。
