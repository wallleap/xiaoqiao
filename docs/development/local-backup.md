# 本地完整备份与恢复

设置页保存和恢复 `.xqbackup` 完整包，包含账本、账目、账户、预算、分类、余额调整、图片及自定义图标资源。格式、资源契约和中断回退见 [完整备份包 v1](backup-package.md)。WebDAV 使用同一格式，见 [WebDAV 说明](webdav-backup.md)。

保存通过系统文件选择器选目标位置。恢复先选文件、复制到暂存区并校验，再显示账本、账目、账户及资源数量，用户明确确认后替换。取消预览不改变现有数据。恢复前保留数据库和资源的完整副本，可再次导出。

LocalLedgerBackup 是内部数据库快照与恢复的串行适配层。LedgerBackupPackage 是用户备份入口，负责清单、资源、ZIP 校验及资源共同回退。启动时先处理数据库与资源回退记录，再执行原有初始化/升级检查。

本轮无数据库表变更、迁移或真实账本恢复操作。当前备份包不加密，最大 32 MiB，接收结构匹配的 V2 数据库和 v1 清单。跨数据库版本转换、损坏主库离线重建及旧 `.db` 文件导入不在本轮范围。

原有 LocalLedgerBackup 原生测试继续验证数据库恢复、前副本和待回退文件的启动处理。新增 BackupPackage 测试覆盖资源共同恢复；WebDav 测试覆盖完整包上传下载与预览。设置页界面用例打开系统文件选择器后取消，验证不会替换数据。账目图片选择、压缩、详情预览和附件导出已接入，见 [账目图片附件](attachments.md)。

## 本地图片与容量限制

图片保存在应用持久目录，随完整备份导出。完整备份包最多 32 MiB，图片与图标合计最多 2046 个，超限会提示失败。已保存过的图片解除账目关联后仍保留，并计入完整备份容量。


V6 自定义预算分类颜色兼容（2026-11-14）：当前数据库版本为 6，新增可空 custom_color 字段。恢复 v2–v5 备份时在候选副本逐级升级到 v6 后校验，源备份不修改；完整备份 manifest 使用 schema 6，并继续接受旧版本包。旧版应用不支持直接打开 v6，跨版本回退应使用升级前备份。迁移代码与恢复链已同步，实际迁移、备份和恢复未执行，按用户要求未运行测试。


华为云空间文件备份复用同一完整包及恢复流程，接入、账号关联与验证边界见[华为账号与云空间备份](huawei-cloud-backup.md)。
