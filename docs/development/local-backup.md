# 本地备份与恢复

在「设置 → 本地备份与恢复」中，可以通过系统文件选择器将账本保存为 `.db` 文件。恢复时先选择备份文件，查看其中的账本、有效账目和账户数量，再确认替换当前账本。恢复成功后，账目与资产页重新读取数据。「导出恢复前副本」可以另存最近一次恢复前的账本，也可以用它重新走一遍恢复流程。

备份保留当前版本中的账本、账目及其关系、账户、预算、分类和余额调整记录。文件是未加密的数据库快照，含账务数据。当前支持结构与本机一致的 V2 数据库，单文件上限 128 MiB。含附件记录的账本需要后续的附件打包支持。当前账本须先能正常打开，新安装后可从空账本进入设置恢复。WebDAV、跨版本转换和损坏主库的离线重建属于后续工作。

## 数据边界

1. 导出在账本串行队列内调用 HarmonyOS RDB 的 `backup()` 生成独立快照。系统文件选择器授权读写选中的 URI。写完并同步文件后才显示保存成功。
2. 导入先复制到应用数据库沙箱中的暂存文件，以只读方式打开。核对本机 SQLite 表、视图、索引、触发器和版本登记，检查完整性及外键，再读取预览。取消时清理暂存。
3. 用户确认替换后，串行任务再次校验暂存文件。原账本先备份并同步到磁盘，再将副本重命名为待回退文件。随后调用 `restore()`，核对恢复后的结构、完整性、外键和预览数量。通过后，将待回退文件保留为最近的恢复前副本。
4. 恢复途中出错时用待回退副本恢复原账本。应用重新打开时若仍有待回退文件，也会先恢复原账本再读取业务数据。若回退无法完成，保留副本并阻止继续使用该数据库连接。模拟中断覆盖了进程重开路径，断电与存储介质故障尚未验证。

实现依据见 [HarmonyOS RDB 备份与恢复](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/data-backup-and-restore/) 和 [华为文件选择器与数据库转存说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-faqs/faqs-local-database-management-63/)。

## 设备回归

测试使用 UUID 隔离库。原生用例核对恢复后账目、账户余额与预算，覆盖取消、损坏文件、导出并重新恢复恢复前副本，以及待回退文件存在时的启动处理。界面用例从设置页打开系统文件选择器并取消，检查可以返回账目页。

- 主包和测试包的 Hvigor `assembleHap` 通过。主机检查 `node tools/verify-p0.mjs` 共 42 项通过，两个 SQL 生成校验和 `git diff --check` 通过。
- API 26 模拟器中，`aa test` 的 `LocalLedgerBackup` 专项 3/3 通过。系统选择器保留应用下层节点，界面回归通过系统返回手势取消，并检查按钮重新可用。真实目录落盘和在选择器中点选文件尚未做完整的界面验收，数据库读写回环使用应用沙箱文件。
- 同一模拟器全量回归 27/27 通过，含首页滚动、删除转账和还款后的资产刷新及账户校准。复跑前校正了转账用例的汇总预期。旧开户用例曾在键盘收起后未定位到期初余额输入框，同一构建复跑通过。
