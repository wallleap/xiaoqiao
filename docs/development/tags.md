# 标签

2026-11-08，接入标签管理、记账归属、详情展示和首页关键词检索。标签用于跨收支分类组合账目，例如“旅行”“报销”“家庭”，一条账目最多选择 20 个标签。

## 数据与规则

现有 V1 数据库已经包含 `tags` 与 `transaction_tags`，本轮没有新增表或迁移。

- 标签属于当前账本，名称在同一账本内不能重复，名称最长 20 个字符。
- 颜色只保存语义 Token：`brand`、`income`、`warning`、`alert`、`neutral`，具体色值由 Light/Dark 资源决定。
- 支出、收入和转账都通过同一多对多关系关联标签。
- 新增账目可在记账表单多选标签；编辑账目时可增删，清空选择会删除该账目的全部标签关系。
- 标签软删除后不能用于新账目，历史账目仍显示原标签；同名标签可以重新创建。
- 编辑历史账目时，已删除但仍绑定在该账目上的标签可以保留或清除。
- 资金余额、预算和统计金额不受标签影响。
- 首页搜索同时匹配备注、收支分类、账户和标签名称。
- 首页筛选 Sheet 支持账户与多个标签组合；选择多个标签时按“同时包含全部所选标签”收窄结果。

## 代码

- `TagProfile.ets`：标签模型、颜色白名单和输入验证。
- `LedgerWorkspace.ets`：标签新增、改名/改色、软删除，以及账本读取和账目标签查询。
- `RdbLedgerRepository.ets`、`RdbTransferRepository.ets`：在账务事务内验证标签归属并替换关系；标签错误会回滚整个写入。
- `TagManagementPage.ets`：设置页标签管理，支持新增、编辑和删除确认。
- `ExpenseEditor.ets`：记账页多选标签。
- `EntryDetailPage.ets`：详情显示历史标签。
- `LedgerOverview.ets`：从账本快照生成可搜索的标签文本。
- `Index.ets`：首页标签组合筛选、筛选标记和结果摘要。

### 标签管理页样式

- 页面以一行辅助说明、标签数量与右侧新增入口组成；空状态保留主色新增按钮。
- 标签合并为一个白色圆角列表，行高至少 60vp，浅分割线分隔；左侧 8vp 色点与主文字色的 `#标签名` 代替彩色胶囊，与预算分类区分。
- 每行右侧直接显示编辑、删除按钮，保留已有删除确认与历史标签保留规则。
- 编辑 Sheet 使用标签名称字段、52vp 高浅灰圆角输入框与聚焦品牌色细边框；颜色使用小圆点选择，保留选中勾，无额外预览卡。

- 标签颜色第一项使用与预算分类一致的原生 HdsColorPicker 入口：24vp 入口居中放入 44vp 单元，后接原有预设色圆点；选择不透明自定义色后直接更新，点击保存后持久化。
- 自定义色使用大写 `#RRGGBB`，沿用 tags.color_token 字段，无数据库升级；原有颜色 token 保持兼容。支持自定义色的文字与浅色背景展示，管理列表继续以小色点区分。低于 API 26 或无 HDS 能力时提供十六进制输入。
