# 汇率转换

入口在「我的」快捷区，名称和页面标题均为「汇率转换」，保留 `mine_icon_exchange_rates.png`。右上角为 HDS 原生 Lucide plus 菜单，打开币种管理；不再显示刷新菜单。进入页面及切换基准自动读取参考汇率，失败时仍可点击错误提示重试。在线读取沿用 ECB 公开数据、6 小时缓存及共享下载任务，不保证每次进入都发起网络下载。

## 页面与输入

- 默认基准 CNY，固定展示「1 基准币可兑换」，不提供金额输入。
- 列表直接显示在线报价或手动汇率的完整可用精度，不强制保留两位小数，也不按目标币种的小数位取整；例如 JPY 的汇率仍可带小数，小于 0.01 的汇率不会显示为 0.00。实际记账的金额舍入规则保持不变。
- 基准 Sheet 仅显示已开启币种，支持名称／代码搜索；选择后按 1 单位新基准重新读取列表。人民币作为账本基准始终开启。
- 点击列表币种进入当前基准下的手动汇率编辑，例如基准 USD、目标 EUR 时填写「1 USD 可兑换多少 EUR」。保存后标记「手动」，在线报价不会覆盖。
- plus 打开管理 Sheet，可搜索、勾选开启币种、新增币种、编辑资料和旗帜、修改汇率、恢复自动汇率。每行左侧勾选框、旗帜和文字组成单一点击区域，点击切换启用状态，右侧编辑按钮独立操作；左侧用普通 Row 统一处理点击，勾选圆形和图标仅显示状态，不嵌套 Button／Checkbox；文字禁止复制、旗帜禁止拖拽，右侧编辑按钮为独立相邻区域。仅未被引用的自定义币种可以删除；内置币种不可删除。
- 新增需填写三位大写字母代码、名称、符号、小数位（0～4，默认 2）、相对于当前基准的正汇率。代码唯一；已有币种代码和小数位不可更改。汇率使用独立自定义键盘，最多 16 位整数、12 位小数。
- 旗帜选择器可搜索地区代码或英文名称，使用已导入的 271 个旗帜／地区素材。可不选旗帜，使用圆角背景＋货币代码占位。旗帜保持原色，不降低文字和旗帜透明度。
- 无启用目标币种、搜索无结果、缺少手动换算路径或在线失败均显示相应状态。普通刷新保留旧值；配置变更清空旧结果，防止删除的手动值或已停用币种继续显示。异步读取使用请求版本，关闭页面或新设置生效后拒绝旧结果回写。

## 全系统汇率规则

`OfficialExchangeRates.quote()` 是页面、记一笔、预付款、退款／报销换汇和账户资产估值的共享入口：

1. 同币种返回 1。
2. 有直接手动币种对时优先使用，反向自动取倒数；保存一方向会替换该币种对原有的任一方向，避免同时保存互相冲突的正反值。
3. 两个内置币种没有直接手动值时读取在线报价，不借用其它手动币种对强行覆盖在线方向。
4. 涉及自定义币种时，优先找最短手动路径；不能完全连通时，经手动路径连接到内置币种，再结合内置币种间报价换算。无连通路径时明确报缺少手动汇率，不编造 1:1。路径乘除保留 BigInt 分数，到最终报价才舍入为最多 12 位小数；超出可表示范围则报不可用。
5. 手动／组合手动结果使用 `manual` 来源，保存账目时保留该标识；在线结果保留 ECB 实际报价日期和缓存回退标识。组合结果使用所涉及报价最早日期，不把今天伪装为在线报价日期。

记账、账户和预付款选择器过滤已停用币种。币种定义仍留在完整目录中，保证历史金额格式化、已有账户估值和历史记录查看正常。修改全局汇率不会更新已保存账目的折算金额、结算快照或预付款历史账本金额；新记账保存时自动读取新设置，当前外币账户估值直接读取新设置。离开汇率页后刷新首页及资产汇总。

### 记一笔币种选择

点击「记一笔」币种行打开 75% 高度 Sheet，使用旗帜＋名称的纵向列表，代码作为辅助文字；支持名称／代码搜索，显示已开启的内置及自定义币种，并标识当前项。点击整行立即选择并关闭；再次选择当前币种只关闭，不修改草稿。沿用不产生按压形变的沉浸材质，列表保留弹性滚动；打开前收起金额键盘并清除焦点，避免延迟焦点任务打断搜索。

币种卡片仅保留币种选择行，不显示手动汇率、折算提示、获取按钮、报价说明或实际到账／扣款输入。新账目保存时自动通过共享汇率服务读取全局手动设置或在线／缓存报价，沿用原有金额折算规则；获取失败明确提示尚未保存，可重试或到“汇率转换”设置，不写入账目。读取期间锁定保存；编辑历史账目沿用已保存换算快照，缺少必要汇率时才读取。

切换币种保留主金额及当前记账类型下的优惠、手续费和抵扣金额，清除账本汇率、结算汇率、实际结算金额及报价日期／来源；来源重置为手动，旧报价版本失效。不对金额进行自动舍入：目标币种不能容纳已填小数位、表达式未完成或金额超限时，留在原币种并在 Sheet 提示修改。只允许移除冗余小数零，例如 `12.00` 可切换到零位小数币种，`12.34` 不可。转账保留收款账户；转出账户与新币种不一致时清除该账户，需重新选择。编辑历史账目仍禁止更换币种。

`node tools/verify-expense-currency-picker.mjs` 在主机执行生产金额校验和编辑器事件方法，覆盖选择、搜索、停用／自定义币种、精度拒绝、换算清空、转账账户兼容、异步焦点隔离、自动读取汇率、失败不写入及成功保存；不代表原生 Sheet 手势或视觉验收通过。

## 保存、备份与恢复

复用现有 `currencies` 表，保存定义及 `is_enabled`；旗帜与手动币种对保存于 `db_meta.currency_settings_v1`（version 1）。无需新增表、字段、索引或数据库版本迁移。最多保留 200 个币种、1000 个手动币种对。

`RdbCurrencySettings` 使用现有串行会话事务：读取、校验、定义修改和配置写入共同提交；提交后才发布运行时目录。失败回滚，不发布半成品。数据库外键阻止删除已被账户、历史账目等引用的币种，已归档／软删除的数据也受保护。

完整本地／云端备份包含整个数据库，因此定义、启用状态、旗帜和手动值自动一起备份及回滚。备份校验额外检查币种设置；恢复完成后重新加载运行时目录。旧备份没有此设置键时使用空手动汇率和默认旗帜，启用状态读取备份币种表。内置种子目录与运行时目录分离，避免旧版本备份升级时混入当前自定义币种。

不新增权限、依赖或外部服务；请求只包含公开报价查询，不发送账本、金额或个人资料。

## HDS 与宫格布局

保持直接 `HdsNavigation > List`，使用 MINI、`enableComponentSafeArea`、`LayoutPolicy.matchParent`，不叠加 `avoidLayoutSafeArea` 或手动系统顶部补偿。标题栏菜单使用 `value[].content`；保留 IMMERSIVE／ADAPTIVE、IMMERSIVE_GRADIENT_BLUR、`bindToScrollable`。基准、固定 1 单位说明和搜索处于同一自然高度 ListItem 内，随内容滚动。使用单个原生 Sheet 根据入口显示基准选择或币种管理，复用 menu 沉浸材质和系统关闭按钮，键盘避让使用 TRANSLATE_AND_RESIZE。编辑 Scroll 使用 TopStart 内容对齐，表单 Column 靠上排列并使用 16 vp 内边距、16 vp 圆角及半透明底；内容不足一屏时也不垂直居中。汇率相关 Sheet 内的管理列表、编辑 Scroll、旗帜 Grid 和基准 Grid 均开启弹性滚动（EdgeEffect.Spring，alwaysEnabled=true），内容不足一屏时也可拖动回弹；Sheet 内按钮关闭 stateEffect，保留实际选中描边／勾选状态，不显示按压灰色高亮。管理／编辑资料／旗帜和基准选择 Sheet 使用单个 LARGE 档位；手动汇率使用单个 55% 高度档位，隐藏拖拽条；内容直接放入 Sheet，不再额外嵌套用于拦截手势的 Scroll；内层滚动容器使用前后双向 SELF_ONLY，保留自身弹性滚动。仅隐藏 dragBar 不是禁用拖拽，单独关闭 EdgeEffect 也不足以隔离外层。主页面列表滚动效果保持原设定。

接口依据：[官方半模态说明](https://developer.huawei.com/consumer/en/doc/HarmonyOS-Guides/arkts-sheet-page/)、[官方嵌套滚动模式](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-container-scrollable-common/)，以及本地 SDK 的 SheetOptions／nestedScroll 定义。手势实际表现仍需设备验收。

币种宫格根据实测内容宽度计算列数，最小目标宽度 96 vp、间距 8 vp、最多 6 列；大字体扩大目标宽度及行高。旗帜选择器采用更紧凑的自适应宫格。币种卡片独立半透明背景：浅色 `#80FFFFFF`、深色 `#66202224`，14 vp 圆角；border 后设置圆角及裁剪。

### Sheet 按压形变、更新与主题补充

汇率 Sheet 不再直接复用全局 `menu` 材质，因为该材质设置了 `interactive: true`。本地 SDK `@ohos.arkui.uiMaterial.d.ts` 明确将其定义为材质组件的交互形变开关，与 Button.stateEffect 和滚动 EdgeEffect 不同。新增 `presentation/exchange/ExchangeSheetMaterial.ets`，使用同样的 THICK 模糊风格、`interactive: false`，不设置触摸 lightEffect。通过动态导入并在打开 Sheet 前准备好材质，避免旧系统加载 API 26 模块，以及 Sheet 展示后替换材质导致跳动；失败时用主题背景回退。

勾选先事务保存并更新管理列表，不修改搜索词或全局列表刷新版本。行标识固定为币种 code，不再包含 enabled 或全局 revision；勾选和名称显示从当前状态读取。背景页面的配置刷新积累为 dirty 标记，在 Sheet 关闭后一次执行，避免每次勾选重建背景报价列表或重新绑定材质。实际币种设置仍即时保存并发布给共享汇率入口。

直接点击报价行打开的手动汇率 Sheet 高度为 55%，保存／恢复自动后关闭；返回管理列表则按模式调整为 LARGE。表单保持靠上，超出时内部滚动。小数位按钮使用中性主题背景和次级文字，不使用默认系统蓝；“不使用旗帜”使用半透明底和品牌文字；旗帜入口加圆角，资料输入框及汇率输入框显式设置深浅色文字、占位色和光标色。

验证另覆盖专用材质 interactive=false、打开前准备材质、Sheet 内保存不刷新背景、模式对应高度、直接保存关闭，以及勾选不改搜索／revision／其它行标识。以上仍是主机检查，原生材质触摸表现尚未做设备验收。


管理币种卡片的选择事件绑定到整张外层卡片，覆盖文字、旗帜、空白、组件间隙和边缘内边距；内容区域仅显示，不拦截点击。右侧编辑按钮设置 SDK 支持的 `monopolizeEvents(true)` 独占事件，只进入编辑；ClickEvent 不提供 stopPropagation，不在点击回调里调用该方法。人民币保持固定开启，但右侧编辑仍可用。


### 单击反馈与 Sheet 内容弹性

“取消点击弹性”针对的是 immersive 材质的 interactive 形变，不取消内容滚动。币种管理、编辑表单、基准币种及旗帜宫格恢复 Spring(alwaysEnabled=true)，去掉之前额外嵌套的 Scroll；静态沉浸材质仍 interactive=false。

单击卡片先立即更新页面中的勾选，再后台事务保存；保存失败恢复原勾选并提示。连续点击按顺序排队保存，不因某一项正在保存而丢弃其它卡片或本卡片的后续点击。处理事件时按 code 从当前列表查找最新状态，不使用 ForEach 旧闭包携带的 enabled。卡片不额外设置 focusable(true)，右侧编辑保持独立事件。

同样为其它已有 Sheet 的滚动内容启用 Spring(alwaysEnabled=true)：记一笔的标签、分类、账户、转账用途选择；分类图标宫格；预算分类编辑的滚动表单；预付款及退款／报销表单；统计明细列表；首页的账本、筛选、预算弹层。没有滚动区域的短表单保持原结构。

主机验证覆盖保存未完成前的立即反馈、旧点击数据再次切换、忙碌时重复点击不重复写入和失败恢复；不等同于设备触摸事件验收。


### 连续点击、互相取消及闪动修正

卡片 key 固定为 code。勾选图形和名称通过当前 `@State profiles` 读取，而非使用 ForEach 初次创建时捕获的 profile 值；修改勾选不销毁／重建卡片，保存过程中也不切换整张卡片 enabled。右侧编辑同样按 code 取最新资料，避免把旧 enabled 带回编辑保存。

移除选择操作对全局 working 的锁定。每次点击立即只改对应币种，再由现有 RdbSession 排队保存，连续点多个币种或同一币种的反向点击都保留。成功不再用数据库全量快照替换当前界面，因此不会覆盖其它尚未完成的选择。失败仅在该币种没有更新的点击时恢复该币种的已提交状态，不恢复整份旧列表、不取消其它币种。使用每币种版本区分过时失败。

主机回归以延迟写入覆盖：先点 A 再点 B 两项都立即更新且最终独立保存、同一项快速取消／开启的最终状态、旧闭包再次点击、稳定行 key、失败只恢复对应项、编辑读取最新 enabled。触摸命中与原生渲染仍未做设备验证。


### 汇率模块表单交互样式

本次范围仅汇率模块。直接从报价列表打开手动汇率是独立 Sheet，不显示返回按钮，只保留系统关闭；从管理页进入的编辑和旗帜子页面保留返回。

输入字段使用固定标签、48 vp 输入框（汇率为 56 vp）、14 vp 左右内边距、12 vp 圆角、主题输入背景及可见边框。聚焦后边框切换品牌色。货币名称、符号与新建代码均有示例占位；汇率显示清晰方向和独立输入框，继续使用自定义键盘并保留原精度规则。

小数位选择使用完整点击行及下箭头，旗帜选择使用当前值、“更换”和右箭头。已有币种的代码／小数位改为只读文本块，标签右侧显示“不可修改”，不再伪装成可点输入框或禁用按钮。旗帜选择中的代码占位也做成有边框和选中标识的选择项，所有旗帜卡片保留可见边界。主操作按场景命名“保存汇率”／“保存币种”；恢复自动和删除保持次级操作。

复用现有深浅色资源，不新增主题或字体。布局保留顶部排列、内容弹性滚动、无材质按压形变和 55% 手动汇率 Sheet。主机验证检查直接入口无返回、子页面返回、输入焦点边框、已有币种小数位不可选及新建时的选择范围；视觉和系统键盘避让尚未设备验收。


带描边的表单输入框、可选行和旗帜代码占位项使用独立半透明背景 `xq_exchange_form_field_background`：浅色 `#59FFFFFF`（约 35% 白色），深色 `#402E3033`（约 25% 深灰）。仅改变背景层，边框、文字、旗帜和焦点色保持原有清晰度；搜索框和保存按钮保留各自样式。


汇率管理／表单 Sheet 的外层左右间距由 24 vp 收紧为 16 vp，表单卡片内边距由 16 vp 收紧为 12 vp，输入框相对 Sheet 的总左右留白从 40 vp 降为 28 vp。顶部统一 40 vp 最小高度并垂直对齐；子页面返回使用 40 vp 点击区的 Lucide 左箭头（22 vp 图标），与标题间隔 8 vp，不再显示文字“返回”。直接打开手动汇率仍不显示返回入口；保留系统关闭按钮所需的右侧空间。


### Sheet 模糊配置与表单背景

查阅本地 SDK SheetOptions 及官方文档，原生 Sheet 提供整块面板 blurStyle／systemMaterial，没有独立顶部渐变模糊选项。HDS 标题栏支持 GRADIENT_BLUR／IMMERSIVE_GRADIENT_BLUR，当前 Sheet 自绘 Row 标题不具备该配置；本次只核实接口，不将颜色渐变伪装成渐变模糊，也不改写标题栏结构。

表单外层使用独立半透明面板色 `xq_exchange_form_panel_background`：浅色 #B3FFFFFF、深色 #B3202224（约 70% 不透明度）。描边输入／选择／只读块的 `xq_exchange_form_field_background` 更新为浅色 #99F1F3F5、深色 #992E3033（60% 不透明度）。提高背景层可辨认度，仍可透出底层材质；不降低文字和图标透明度。

接口来源：[SheetOptions](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/ts-universal-attributes-sheet-transition/)、[HDS Navigation](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ui-design-hdsnavigation/)。


### 普通与只读表单颜色

普通描边使用专用 `xq_exchange_form_border`：浅色 #14000000（约 8% 黑），深色 #24FFFFFF（约 14% 白），聚焦仍使用品牌色。已有币种代码／小数位的只读块使用独立描边 `xq_exchange_form_readonly_border`（浅色 #0A000000、深色 #10FFFFFF）和背景 `xq_exchange_form_readonly_background`（浅色 #B3E5E7EB、深色 #B3232528）；配合次级文字和“不可修改”，使其与可输入／选择项区分。只读块仍为 Text，不响应输入或选择。


### 新增币种已保存但列表不显示

修复 RdbCurrencySettings.save 在事务尚未提交时调用 querySql 回读目录的问题：读连接可能只能看到已提交的旧目录，导致数据库已新增而运行时目录仍不认识新代码。现在事务中构造并校验将要写入的完整目录，提交成功后发布这个确定结果，不再在提交前回读；更新已有币种保留原顺序。

回归使用临时 SQLite WAL 数据库的独立读／写连接。旧实现会在保存后触发 UNSUPPORTED_CURRENCY，修改后验证新增目录、启用状态、手动报价和列表均可用，并保留失败回滚测试。之前单连接测试看不到此连接隔离问题，现已改为分离连接执行。

每次进入汇率页面先从数据库重载目录再查询，可恢复此前已落库但未发布的币种，无须重复新增。自定义币种在管理及报价列表中优先显示；新增成功后关闭 Sheet 时清除主列表旧搜索并回到顶部，普通勾选／编辑不清除搜索。配置加载失败显示明确错误，重试会重新加载配置。

本轮没有操作设备数据库或执行数据修复。文档依据：[关系型数据库读写连接说明](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/data-persistence-by-rdb-store/)。


### 基准选择器加载状态

基准币种胶囊及基准宫格不再因 loading 禁用；等待旧基准的在线报价时仍可打开并选择新基准。使用现有 request 版本及 base 一致性校验拒绝旧请求回写，不以控件灰显锁定用户。基准文本使用 Medium 字重，选币按钮关闭 stateEffect，保留原沉浸材质。回归模拟旧报价未完成时切换 EUR，验证新方向先显示且延迟旧数据不能覆盖。


“恢复自动汇率”仅在基准和目标均为在线报价支持的内置币种、且二者不相同时显示。涉及自定义基准或自定义目标时隐藏，方法入口同样拦截，防止清除没有在线替代的手动值；新建币种也不显示此操作。
