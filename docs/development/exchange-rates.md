# 汇率查询

入口在「我的」快捷区，名称为「汇率查询」，使用用户提供的 `mine_icon_exchange_rates.png`。不恢复已移除的资产账户、图表统计入口。图标资源本身不改色、不重绘。

## 页面行为

- 默认基准币种人民币，显示「1 CNY 可兑换」，右侧为兑换到目标币种的参考汇率。
- 支持选择项目现有的全部币种为基准；列表排除基准币种本身。
- 可按币种中文名称或英文代码搜索；右上角「重新读取」重新调用现有报价服务。
- 首次显示读取中，刷新保留已有列表并显示更新中；全部失败时显示网络／读取失败和重试入口，单个币种不可用时只标记该行。
- 显示每行的实际报价日期，使用 ECB_CACHE 回退结果时标记「缓存报价」。不把请求当天伪装成报价日期。
- 切换基准时清空上一基准结果，避免错误方向；离开页面后拒绝异步结果回写，重新进入可以再次读取。
- 支持标题栏返回与系统返回。不新增金额输入、换算保存或自动改写记账汇率。

## 数据来源与边界

复用 `OfficialExchangeRates.quote()`，不新增服务接口、权限、依赖或数据库字段。现有服务使用欧洲央行公开数据、6 小时缓存与共享下载任务；本页「重新读取」仍遵循现有缓存策略，不绕过缓存强制请求，不修改服务行为。报价方向始终为 target/base，保留服务返回的精度。

页面只请求公开汇率，不向外部发送账本、账户、金额或个人资料。本轮本地验证使用模拟报价，没有触发真实网络请求。

## HDS 结构

设备截图显示首版标题整体下移，基准币种栏与首项内容重叠。此页撤掉 bottomBuilder 固定栏，将基准币种选择、兑换单位、来源和搜索放入同一自然高度的 ListItem.Column，按顺序测量布局，不添加固定标题高度或顶部补偿。

根节点仍为 HdsNavigation，内容直接为绑定同一 Scroller 的 List；不在两者间添加满高 Column／Row／Stack。沿用现有搜索页的标题安全区配置：只启用 enableComponentSafeArea，移除 avoidLayoutSafeArea 的额外避让及 HDS 自身 ignoreLayoutSafeArea；HDS 和 List 高度使用 LayoutPolicy.matchParent，避免百分比高度只移动位置却未重新测量可用尺寸。

- HDS 仅显示标题、返回与原生刷新菜单，菜单使用 value[].content。
- 基准选择器随内容滚动，不再占据标题栏的固定底部区域；选择器保留原 action 沉浸材质。
- 保留 IMMERSIVE／ADAPTIVE、IMMERSIVE_GRADIENT_BLUR 及 bindToScrollable。
- 隐藏滚动条，内容不足仍允许弹性滚动。

本地 SDK 核对来自 UIDesignKit 的 @hms.hds.hdsBaseComponent.d.ets 和 ArkUI common.d.ts 的安全区／matchParent 说明。新布局未作设备验收，静态结构核对不代表真机效果验证通过。

## 验证

`node tools/verify-exchange-rates-page.mjs` 执行生产查询和页面生命周期方法，覆盖：基准／目标方向、精度与日期保留、缓存标识、单币种失败、整体失败保留旧值、中英文搜索、离页拒绝回写、重新打开及更换基准。

`git diff --check` 检查改动格式。另执行个人汇总和预付款主机回归，避免首页路由和我的页改动影响已接入功能。

手动点击右上角重新读取或失败重试时，立即弹出「正在读取汇率…」；完成后显示读取完成、缓存报价或失败提示，部分币种不可用时提示数量。首次自动加载和切换基准仍只显示页面内加载状态，不额外弹提示。离开页面后不显示完成提示，按钮读取中禁用以避免重复点击。

连续切换基准修正：ForEach 行标识从目标币种 code 改为基准、目标、汇率、日期、缓存状态和错误状态的组合，避免切换或缓存快速返回时复用旧报价节点。单列币种选择兼容 number 与单元素 number[]，无效索引忽略；滚动复位使用 best-effort，异常不阻断 reload。回归以固定欧元参考值连续验证 USD → EUR → JPY → CNY 的实际交叉汇率及行 key 变化。
