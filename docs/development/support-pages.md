# 帮助、反馈与关于页面

“我的”页在“导入与导出／备份与恢复”卡片下新增服务卡片，三行依次为帮助中心、意见反馈、关于我们。沿用 52 vp 行高、20 vp 图标、14 fp 常规字重、16 vp 右箭头、左右 16 vp 内边距，分割线起点 48 vp、终点 16 vp。新卡片未登录、账本未就绪时也可打开，恢复忙碌时禁用。原有数据入口的就绪保护不变。

三个入口分别进入 SupportPage 的独立页面状态，不显示主导航页签。HdsNavigation 绑定实际 Scroller，使用 IMMERSIVE／ADAPTIVE 与 IMMERSIVE_GRADIENT_BLUR，处理上下系统安全区与系统返回。返回“我的”恢复离开时滚动位置。页面左右 16 vp、实色内容卡片，卡片外说明额外内收 8 vp，表单浅底描边、焦点品牌色，按钮显式采用主题色。

- 帮助中心：本地常见问题，可搜索问题及回答、逐项展开。内容覆盖本地记账、账本周期、汇率、预付款、备份、导入导出、外观。无需联网请求。
- 意见反馈：必填主题（80 字）和反馈内容（2000 字），联系方式选填（100 字）。收件邮箱由用户指定为 vonnelu@163.com。点击“打开邮件应用”通过系统 mailto URI 带入收件人、主题、正文与运行时应用版本；仅打开草稿，由用户在邮件应用中确认发送。分别 URI 编码主题／正文，不拼接用户输入为额外邮件参数。不自动附加账目、账号、日志或设备标识。
- 打开邮件失败时保留已填内容，提示邮箱；“复制反馈内容”复制收件邮箱及正文，由用户自行粘贴发送，失败显示原因。两种操作均防止重复提交。不把打开草稿、复制成功表述成邮件发送成功。不持久保存反馈；有内容时，页面返回和系统返回均先确认丢弃。
- 关于我们：现有应用 Logo、应用名称资源、简短功能说明、运行时 versionName／versionCode、反馈邮箱。版本读取失败可重试；不编造隐私协议链接、企业主体或权益。

验证：`node tools/verify-support-pages.mjs` 使用生产纯函数和生产页面异步方法，模拟系统邮件、剪贴板、版本读取与返回确认；不实际发邮件或操作剪贴板。配套执行个人汇总、SnackBar 返回回归脚本与资源引用检查。主机验证不等于 ArkTS 原生编译／真机验收；系统邮件客户端对 mailto 的支持、键盘避让、大字号和浅深色视觉仍需设备确认。
