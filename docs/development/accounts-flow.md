## 用户行为与边界

资产Tab接通正式账户列表和净资产汇总，保留现有悬浮Tab Bar、HdsNavigation和正文滚动。显示CNY净资产、总资产、总负债；汇总按有效资金变动的正负余额计算，且只包括“计入总资产”的账户。已归档账户不进入总资产、总负债及净资产汇总，但账户余额与历史流水保留；恢复使用后按“计入总资产”设置重新参与汇总。

新增页提供账户名称、资产/负债类型、品牌图标、期初余额/期初待还金额及“计入总资产”。名称去首尾空白、1–40字符；CNY最多两位小数，最小单位须在安全整数范围内。输入非负金额，资产存为正余额，负债待还金额存为负余额；资产账户暂不在创建时录入负的透支余额。零余额也保留一条完整的opening事件。

当前提供现金、微信、支付宝、普通银行卡、工商/中国/建设/农业/招商银行、信用卡、花呗、借呗12种品牌模板。复用现有 `accounts_*` SVG（先前已从rawfile方案按用户要求重命名为media资源）。单色白图标配品牌背景；AccountAvatar保留彩色图标使用主题黑/白底的分支。资源内容未修改。

编辑可改名称、品牌图标及是否计入总资产；账户类型和币种固定，余额只读，不改写期初余额。本轮未接余额校准、删除账户、交易明细页、外币账户或转账。已有归档账户可查看/编辑，并可恢复使用；归档有二次确认，不清理历史账目或余额。

新建账户进入收支记账的账户Sheet。选中名称直接绑定状态，保存收支后首页和资产页刷新。无论从哪个Tab新增收支，保存成功回到账目Tab；取消返回原Tab。编辑旧账允许保留原归档账户；新账保存时在事务内重新检查账户仍使用中，避免已打开的表单写入刚归档的账户。

## 写入与精度

- AccountDraft校验账户ID、名称、类型、白名单品牌、CNY币种、期初余额符号及安全范围，并复制输入快照。
- RdbAccountRepository.create在同一个RdbSession串行事务内创建accounts、draft opening调整及对应adjustment movement，然后发布调整。发布失败整体回滚，不留下空账户、draft或孤立movement。同ID重试拒绝，不重复建账。
- 期初余额不是income/expense，没有transactions记录，不占预算。负债还款/收入通过普通正向movement减少负债，支出增加负债；删除收支沿用既有有效变动规则重新反映余额。
- 元数据编辑和归档/恢复必须匹配ID、类型/币种（编辑）及revision；失败提示返回刷新，不覆盖新版本。元数据编辑忽略opening字段，不修改任何余额事件。
- 账户列表从v_effective_movements逐笔读取整数文本，用BigInt聚合，避免浮点与SQLite SUM溢出。最终显示保持精确字符串；读出不支持的币种时资产页显示错误而不把它当成人民币。
- 归档不设置deleted_at_ms；收支选择器查询只含未归档账户。历史详情仍能读取已归档关联。

## 新增账户保存校验

“保存账户”仅在正在写入、外部账户操作进行中或版本冲突时禁用。名称或期初金额不合法时，点击保存显示明确提示并定位输入项，不再因期初金额无效静默禁用按钮；写入前仍使用原有金额精度、非负值与范围校验。期初余额 0 可正常保存。

保存前收起输入焦点采用尽力执行方式，不依赖期初金额框是否曾获得焦点；焦点控制器失败不能阻止有效账户写入。写入失败同时通过 Toast 展示已有错误提示，避免提示落在滚动区域之外。手动回归：输入名称、保持期初余额 0 且不聚焦金额框，直接保存；再验证输入余额后从自定义键盘保存。

账户编辑器通过普通 `amountCurrency()` 方法读取币种。此处不使用自定义 getter：本地 ArkUI 编译缓存中 getter 被省略，而调用点仍读取该属性，造成保存校验及负债账户标题访问未定义币种；保存异常文案再次访问该属性还会掩盖原始错误。

### 生成与来源

原始 SVG 保留于 tools/bank-icons/source，清单 tools/bank-icons/catalog.json 记录来源 URL/网页、下载日、原始哈希、名称、关键词及浏览器实测 getBBox 得到的正方形 viewBox。`python3 tools/generate-account-bank-icons.py` 校验哈希，拒绝可执行/外链 SVG 属性，并生成媒体 SVG、domain/model/BankAccountStyles.ets、presentation/ledger/BankAccountIcons.ets 与文档清单。按实际图案边界加 4% 留白归一化，使不同来源的空白不会让账户头像忽大忽小。

彩色版保留原有路径与渐变；白色版只将可见填充/描边统一为白色，保留轮廓、透明区域、路径洞和遮罩内容。仅改色不能保证复杂多色标识的层次与彩色版完全等价，实际可在选择器比较后选用。银行品牌色按素材颜色自动估算，不声明为各银行正式品牌规范色。

图标版权/商标归相应权利人；来源为第三方素材汇集站，不将其描述成银行官方授权图库。本轮只读取公开页面和静态素材，没有发送项目代码、账户或账本数据。
