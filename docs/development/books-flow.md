# 账本管理闭环

2026-11-21：新增账本币种与月起始日，当前规则、V11 迁移和验证见[账本设置](book-settings.md)。下文保留早期实现记录。

首页标题中的账本选择器已接入真实管理功能，支持切换、新建、改名、归档和恢复。第一轮不提供删除、拖拽排序或跨账本批量操作。

## 数据边界

- 账目、分类和预算按 `book_id` 隔离；资金账户、账户余额、转账和余额校准继续全局共用。
- 当前选择的账本保存在 `db_meta.active_book_id`。应用正常启动时读取该值；值缺失、被删除或已归档时，回退到排序最前的未归档账本并持久化。
- 切换账本会重新读取首页快照，并清理当前搜索、收支筛选和账户筛选，避免上一账本条件误用在新账本。
- 新建账本在当前业务事务内写入账本记录、复制默认分类并切换为当前账本。分类使用新 UUID，二级分类父子关系重新映射，不共享可变分类记录。
- 默认预算仍由缺失月份的行级默认值提供；不同账本修改月预算只写各自账本。
- 账本名称去除首尾空白后为 1 至 40 个字符，并拒绝与现有未删除账本重名。改名使用 revision 乐观并发检查。
- 归档保留账目、预算和分类，只阻止该账本继续作为当前账本使用。至少保留一个未归档账本；归档当前账本时在同一事务内切换到另一可用账本。恢复后需由用户选择切换。

本轮复用现有 `books`、`categories` 和 `db_meta`，没有表结构变更或数据库迁移。完整备份包会包含账本、分类、预算以及当前账本选择。

## 界面

账本 Sheet 继续使用 HDS 沉浸材质，正文按账本数量自适应高度。未归档账本支持点击切换，卡片的“编辑”和“归档”操作分开显示；归档账本只在“已归档”区域显示并由“恢复使用”操作恢复。修改进行中会锁定切换、编辑、归档和保存，避免重复写入。

## 验证

`Books` 原生隔离库用例覆盖：

- 默认账本读取与新建账本后的自动切换。
- 默认支出、收入分类复制及二级分类父子关系重建。
- 两账本账目、详情、月预算相互隔离。
- 关闭并重新打开工作区后当前账本及账目保持。
- 改名、revision 冲突、同名拒绝、归档当前账本自动回退、最后一个账本保护及恢复。

主应用和测试包均通过 Hvigor `assembleHap`；API 26 模拟器完整原生回归 40/40 通过，主机业务检查 44/44 通过。最终 Sheet 高度和关闭按钮间距调整后，又单独重跑 `Books` 2/2 与首页 UI 1/1。实际截图检查了账本 Sheet 的材质、闭合状态、标题、操作按钮和单账本紧凑布局。平板、折叠屏、大字号及 API 24/25 回退留待发布前专项验收。

“我的”统计卡片仅把固定列类型传入 personalStat Builder，值、loading、error 在 UI 表达式中直接读取 @Prop，避免条件节点捕获普通参数而保留“更新中”。刷新结束仍由 finally 清除加载状态；失败保留旧值并显示更新失败与重试入口。主机验证检查异步完成和 Builder 依赖，实际 ArkUI 状态更新需设备验收。
