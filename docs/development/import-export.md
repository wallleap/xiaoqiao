# 导入与导出

2026-11-08，设置页接入“导入与导出”入口，完成当前账本按可选日期范围导出 CSV/Excel，以及 CSV/Excel 选择、表头识别、手动字段映射、预览和确认导入。支付宝、微信真实样本的基础模板识别已接入。

## 当前范围

- 导出日期范围默认当前账目页所选月份，可分别选择开始和结束日期，支持跨月；起止日期当天都包含。
- 可进一步按全部、收入、支出筛选，并按账户筛选；账户筛选同时匹配转出和转入账户。
- 导出数据只来自当前账本，结果按发生时间倒序生成。
- 文件编码为 UTF-8 BOM，换行使用 CRLF，所有文本使用双引号转义。
- 金额以十进制文本输出，不使用浮点数计算。
- 字段包括日期、时间、类型、分类、账户、转入账户、备注、商户、地址、币种、原金额、优惠、实付金额、转账手续费、转账优惠、转账用途、手续费是否计入预算、标签、附件数和账目 ID。
- 标签以 `|` 组合输出；文本内逗号、引号和换行不会破坏列结构。
- CSV/Excel 只生成表格文件；另提供“导出含图片 ZIP”，打包当前筛选范围 CSV、附件清单和去重图片。完整恢复仍使用本地/WebDAV `.xqbackup`。
- CSV 中不包含 WebDAV 密码、令牌或任何连接凭据。
- Excel 导出生成标准 Office Open XML `.xlsx`，单工作表“账目”，含冻结表头和数值金额单元格。
- CSV 和 Excel 导出共用 20 个可选字段，用户可取消不需要的列；两种格式切换不会改变字段选择。
- Excel 导入支持选择工作簿中的工作表，读取内联字符串、共享字符串、数值日期序列及公式单元格的缓存值，并复用 CSV 的字段映射与事务导入。
- 外部 Excel 文件使用 Deflate 压缩；导入时先复制为临时 `.zip`，再由系统 zlib 解压，兼容本应用导出和微信实际账单。
- 支付宝样本使用 GB18030 编码，可跳过导出信息并定位第 24 行真实表头。
- 微信样本可跳过 XLSX 说明行，定位第 18 行真实表头，并读取 Excel 日期小数中的具体时间。
- 导入预览可手动选择前 50 行中的任意表头行；CSV 还可切换逗号、制表符和分号分隔符。
- CSV/Excel 导入支持日期、类型、金额、分类、账户、备注、商户、地址和来源编号映射，账户可不使用。
- CSV/Excel 导入还支持独立转账金额、转入账户、转账用途、手续费、还款优惠和手续费是否计入预算映射。
- 金额统一按绝对值写入；类型列优先。没有类型值时，负数按支出、正数按收入。
- 日期支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`、`YYYY年MM月DD日`、`YYYYMMDD` 和 `MM/DD/YYYY`；可附带 `HH:mm`、`HH:mm:ss` 或上午/下午时间。
- 日期与时间也可分别占两列，在字段映射中分别选择“日期”和“时间”。
- 日期-only 使用该日期的本地中午作为稳定排序时间；带具体时间时保留实际时分。
- 导入会按分类完整路径或名称、账户名称匹配当前账本。
- 支出与收入分类分别建立索引，同名分类不会串用；类型值支持“交易支出、交易收入”等包含明确关键词的写法。
- 分类匹配不上时默认归入当前收支类型已有的“其它/其他”；没有兜底分类时创建“其它/其他收入”。开启“自动创建缺失分类”后按文件原名称创建。
- 账户匹配不上时默认不创建账户，账目不关联账户，也不影响任何账户余额；可在字段映射页开启“自动创建缺失账户”。
- 缺失账户创建后名称匹配，资产/负债类型由名称规则判断，创建后可在资产页继续校准。
- 支持普通转账、信用卡还款、借款还款、充值和提现导入；转出与转入账户必须不同，还款的转入账户必须是负债账户。
- 转账本金不计入收入、支出或预算；手续费计入支出并可选择是否计入预算，还款优惠单独保留且不超过转账本金。
- 商户按规范化名称关联 `merchants` 主数据并去重，同时把原始商户名称和地址快照保存到账目，供详情和历史回溯。
- 交易状态按成功、退款/撤销/关闭、零钱通内部流转和待确认四类处理；退款、撤销和内部流转默认跳过并保留原因。
- 每次导入默认使用 `balance_mode=preserve`，保留账目与账户关联，但不改变当前账户余额，也不默认计入预算。
- 每个文件可在预览中切换“按记录更新余额”；切换后本批记录使用 `balance_mode=apply`，账户余额和首页资产同步更新。
- 确认前只做预览；确认后批次、导入行和账目在同一事务内写入，任一失败全部回滚。
- 导入中按已处理有效账目显示实时进度；事务提交后立即刷新首页账目列表，关闭导入页时再同步一次。
- 可选映射账目 ID、交易单号或订单号；文件内重复和历史账目已有的来源编号会在预览中标记并默认跳过。
- 其他问题行（日期、金额、类型或状态无效）默认跳过并显示具体原因，不允许选中导入。
- 预览会按“日期无效、金额异常、分类未匹配、账户未匹配、交易状态跳过”等类别汇总问题，并显示本批将新建的分类和账户数量。
- 字段映射、表头行、分隔符和自动创建选项可保存到 `import_profiles`，下次选择同来源文件后直接复用或更新模板。
- 最近 10 个导入批次展示来源文件、总量、成功/跳过/问题数量和状态；展开后可查看逐行原始值、校验状态和问题原因。

## 地图坐标导入导出（2026-11-12）

CSV、Excel 及复用 CSV 的导出格式新增可选字段“纬度”“经度”，默认一并选中，位于地址之后。以十进制度数输出，固定六位小数；例如纬度 `39.916345`、经度 `116.397155`。无坐标时两列留空，零坐标正常输出，不以零代替缺失值。Excel 复用同一字段定义和取值函数，坐标单元格按文本保留六位小数。需要往返保留地图时，请同时导出两列。

CSV 与 Excel 导入自动识别中文“纬度”“经度”、英文 `latitude` / `longitude`，以及 `lat` / `lng` / `lon`，也可在映射区手动选择。两列同时留空或旧文件不含坐标列时，按无坐标账目导入；只填一项、格式不合法或越界时，该行在预览中显示问题且不能导入。允许十进制科学计数法，不接受带单位、十六进制、NaN 或 Infinity 的值。纬度范围为 -90～90，经度为 -180～180，转换为百万分之一度整数保存；不自动判断或转换坐标系。

有效坐标会单独显示在导入预览中，取消再勾选该行不会丢失位置。字段映射模板保存两项坐标映射；旧模板缺少这些字段时按未映射处理，可手动补选并保存。支出、收入、转账共用位置写入逻辑，写入现有坐标列并随原导入事务提交，不新增表或迁移。导入后详情页可根据坐标显示地图；只有地址文字的文件不自动补坐标。重复记录仍沿用原有提示和选择机制，不自动覆盖已有账目。

按用户要求，本次未运行测试、构建或设备验证，交由用户手动验收。仅审阅代码差异及执行 `git diff --check`，不将实现描述视作运行验证结果。

手动验收建议：

1. 分别选择一笔有地图位置的支出、收入、转账，导出 CSV 和 Excel，确认地址及两列坐标存在；再导出一笔纯文字地址账目，确认坐标为空。
2. 在测试账本中导入两种文件，检查映射和位置预览，取消再勾选一行，确认导入后地图位置与原账目一致。
3. 把一行改为纬度 `0`、经度 `0`，确认识别为有效位置；把另一行只保留纬度或改成纬度 `91`，确认提示问题且不能导入。
4. 导入没有坐标列的旧文件，以及套用旧映射模板，确认文字地址仍可导入；手动映射坐标后另存模板，再检查映射是否保留。

## 报销与退款（2026-11-12）

支持部分／全额回款的独立行导出与关联导入，新增“关联支出ID”“待报销”“计入预算”“预算分类”四列，共 26 个可选字段。回款金额按正数导出，类型区分退款／报销；导入先处理原支出，再关联回款。目标支出缺失、歧义或累计回款超额时整批回滚，不转成普通收入。恢复关联需同时保留账目ID、类型、实付金额与关联支出ID；导出范围只含回款时，目标账本必须已有对应支出。预算分类未匹配需先创建或恢复同名分类。旧文件没有预算映射仍按原规则不计预算。保留余额／影响余额策略同时作用于回款。实现与用户手动验收步骤见[报销与退款](expense-recoveries.md)。本轮未运行测试或构建。


预算分类颜色列（2026-11-14）：CSV／Excel 统一增加可选“预算分类颜色”，导出为预设令牌或大写 #RRGGBB，自定义颜色来自 v6 可空字段。导入自动识别及手动映射均支持该列，旧配置缺列仍兼容；保留原先同名预算分类匹配规则，不创建或修改分类，指定颜色时须与现有分类一致，否则预览报错。完整备份用于直接保留分类配置；表格导入空账本前须先创建同名同色分类。git diff --check 通过，未构建或运行测试。

## 自动创建账户的事务可见性

导入内新建账户后，仅在插入成功时将账户 ID、币种和资产/负债类型记入批内缓存。校验新账户时使用这些已写入的元数据，已有账户继续使用 `querySql()` 校验，避免读连接看不到未提交记录。不得用 `RdbStore.execute()` 执行普通 SELECT，该语句在设备上不受支持。仍检查账户 ID、币种、未删除状态，以及还款转入账户必须为负债账户的限制；整批导入继续保持事务提交或回滚。

手动回归：勾选自动创建账户，导入包含新账户的收支及转账；确认同名同币种账户在批内复用、不同币种分开创建，且还款转入资产账户仍被拒绝。

导入历史文件名展示时尝试解码 URI 转义，异常时保留原名，不修改存储值。文件名在状态左侧占剩余宽度并单行省略，状态保留完整宽度；长工作表名也单行省略，避免撑出卡片。
