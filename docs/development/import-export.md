# 导入与导出

2026-11-08，设置页接入“导入与导出”入口，完成当前账本按可选日期范围导出 CSV/Excel，以及 CSV/Excel 选择、表头识别、手动字段映射、预览和确认导入。支付宝、微信真实样本的基础模板识别已接入。

## 当前范围

- 导出日期范围默认当前账目页所选月份，可分别选择开始和结束日期，支持跨月；起止日期当天都包含。
- 可进一步按全部、收入、支出筛选，并按账户筛选；账户筛选同时匹配转出和转入账户。
- 导出数据只来自当前账本，结果按发生时间倒序生成。
- 文件编码为 UTF-8 BOM，换行使用 CRLF，所有文本使用双引号转义。
- 金额以十进制文本输出，不使用浮点数计算。
- 字段包括日期、时间、类型、分类、账户、转入账户、备注、商户、地址、币种、原金额、优惠、实付金额、转账手续费、转账优惠、转账用途、手续费是否计入预算、标签和账目 ID。
- 标签以 `|` 组合输出；文本内逗号、引号和换行不会破坏列结构。
- 导出入口只负责生成表格文件，不包含图片原件或完整恢复能力；图片和资源仍使用本地/WebDAV 完整备份。
- CSV 中不包含 WebDAV 密码、令牌或任何连接凭据。
- Excel 导出生成标准 Office Open XML `.xlsx`，单工作表“账目”，含冻结表头和数值金额单元格。
- CSV 和 Excel 导出共用 19 个可选字段，用户可取消不需要的列；两种格式切换不会改变字段选择。
- Excel 导入支持选择工作簿中的工作表，读取内联字符串、共享字符串、数值日期序列及公式单元格的缓存值，并复用 CSV 的字段映射与事务导入。
- 外部 Excel 文件使用 Deflate 压缩；导入时先复制为临时 `.zip`，再由系统 zlib 解压，兼容本应用导出和微信实际账单。
- 支付宝样本使用 GB18030 编码，可跳过导出信息并定位第 24 行真实表头。
- 微信样本可跳过 XLSX 说明行，定位第 18 行真实表头，并读取 Excel 日期小数中的具体时间。
- 导入预览可手动选择前 50 行中的任意表头行；CSV 还可切换逗号、制表符和分号分隔符。
- CSV/Excel 导入支持日期、类型、金额、分类、账户、备注、商户、地址和来源编号映射，账户可不使用。
- CSV/Excel 导入还支持独立转账金额、转入账户、转账用途、手续费、还款优惠和手续费是否计入预算映射。
- 金额统一按绝对值写入；类型列优先。没有类型值时，负数按支出、正数按收入。
- 日期支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`、`YYYY年MM月DD日`、`YYYYMMDD` 和 `MM/DD/YYYY`；可附带 `HH:mm`、`HH:mm:ss` 或上午/下午时间。
- 日期与时间也可分别占两列，在字段映射中分别选择“日期”和“时间”。
- 日期-only 使用该日期的本地中午作为稳定排序时间；带具体时间时保留实际时分。
- 导入会按分类完整路径或名称、账户名称匹配当前账本。
- 支出与收入分类分别建立索引，同名分类不会串用；类型值支持“交易支出、交易收入”等包含明确关键词的写法。
- 分类匹配不上时默认归入当前收支类型已有的“其它/其他”；没有兜底分类时创建“其它/其他收入”。开启“自动创建缺失分类”后按文件原名称创建。
- 账户匹配不上时默认不创建账户，账目不关联账户，也不影响任何账户余额；可在字段映射页开启“自动创建缺失账户”。
- 缺失账户创建后名称匹配，资产/负债类型由名称规则判断，创建后可在资产页继续校准。
- 支持普通转账、信用卡还款、借款还款、充值和提现导入；转出与转入账户必须不同，还款的转入账户必须是负债账户。
- 转账本金不计入收入、支出或预算；手续费计入支出并可选择是否计入预算，还款优惠单独保留且不超过转账本金。
- 商户按规范化名称关联 `merchants` 主数据并去重，同时把原始商户名称和地址快照保存到账目，供详情和历史回溯。
- 交易状态按成功、退款/撤销/关闭、零钱通内部流转和待确认四类处理；退款、撤销和内部流转默认跳过并保留原因。
- 每次导入默认使用 `balance_mode=preserve`，保留账目与账户关联，但不改变当前账户余额，也不默认计入预算。
- 每个文件可在预览中切换“按记录更新余额”；切换后本批记录使用 `balance_mode=apply`，账户余额和首页资产同步更新。
- 确认前只做预览；确认后批次、导入行和账目在同一事务内写入，任一失败全部回滚。
- 导入中按已处理有效账目显示实时进度；事务提交后立即刷新首页账目列表，关闭导入页时再同步一次。
- 可选映射账目 ID、交易单号或订单号；文件内重复和历史账目已有的来源编号会在预览中标记并默认跳过。
- 其他问题行（日期、金额、类型或状态无效）默认跳过并显示具体原因，不允许选中导入。
- 预览会按“日期无效、金额异常、分类未匹配、账户未匹配、交易状态跳过”等类别汇总问题，并显示本批将新建的分类和账户数量。
- 字段映射、表头行、分隔符和自动创建选项可保存到 `import_profiles`，下次选择同来源文件后直接复用或更新模板。
- 最近 10 个导入批次展示来源文件、总量、成功/跳过/问题数量和状态；展开后可查看逐行原始值、校验状态和问题原因。

## 代码

- `LedgerCsvExport.ets`：纯函数生成 RFC 4180 风格 CSV。
- `LedgerXlsxExport.ets`：生成标准 OpenXML 工作簿并写入系统保存位置。
- `LedgerXlsxImport.ets`：读取工作簿首个工作表并转换为统一表格模型。
- `LedgerCsvImport.ets`：CSV 解析、表头自动识别、字段映射预览和分类/账户匹配。
- `ImportProfile.ets`：导入模板、批次历史、批次行和预览统计的只读模型。
- `DataExchangePage.ets`：系统文件选择/保存、导出与导入字段映射界面。
- `LocalBackupPage.ets`、`Index.ets`：设置页入口和页面切换。
- `CsvExport.test.ets`：验证 BOM、CRLF、引号转义、金额、标签和转账字段。
- `XlsxExport.test.ets`：验证 ZIP 结构、工作表、XML 转义、数值金额和标签。
- `CsvImport.test.ets`：验证字段识别、问题行、收入/支出导入、导入身份、预算不计入及余额保持。
