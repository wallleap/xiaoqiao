# 账本封面与配色

参考浅色封面的书脊、右侧页边和顶部书签，用原生 Rect、Path 与现有 Lucide SVG 组合绘制，保留线性图标轮廓，不导入新素材或依赖。中心图标、书脊和书签由所选配色统一着色，不为图标提供独立颜色以免脱离封面色系。

## 选择与展示

- 新建／编辑账本：名称、当前封面预览、12 套配色、Lucide 图标搜索和网格、保存／取消。
- 图标目录由当前本地资源生成，共 1,756 个；首次显示 48 个；点击一次「显示更多图标」即展开当前搜索结果中全部剩余图标，随后按钮隐藏；修改搜索词后重新显示首批 48 个。搜索按英文名称及下划线／连字符匹配。
- 账本列表使用 46×55.2vp，首页标题使用 24×28.8vp；均使用对应主题颜色。
- 新账本及旧账本迁移默认鹅黄＋notebook-text。修改名称时未传 appearance 的旧调用保留现有封面。
- 首页载入时读取已有 books()，避免重启后封面回退；保存沿用 revision 校验，冲突不覆盖。

## 数据与迁移

用户已授权 V10 迁移，仅新增 books.cover_palette 与 books.cover_icon；原 books.icon_key 保留不改。配色为固定 key，图标须匹配当前本地目录；数据库另限制配色白名单与图标 key 字符范围。UI 和领域层均不接受文件路径作为图标。

升级前保存 `<数据库名>_before_book_cover_v10.db`，在 RdbSession 事务中迁移，校验旧账本资料、账户资料、账目数量、预算、有效资金流水、外键与完整性；失败走现有事务回滚。普通启动仍要求明确的本地升级确认。本轮不操作设备数据库。

完整备份 manifest schema 为 10，兼容读取 schema 2～9；恢复到隔离候选库后按既有链逐步迁移再替换。两个字段在数据库内，随完整备份（本地、云空间和 WebDAV 共用的包）保留，不新增外部请求。旧应用不支持新版本备份，应保留升级前备份。

## 生成与验证

- `python3 tools/generate-book-covers.py`：生成领域配色／图标 key 目录、资源映射及浅深颜色；只更新 `xq_book_cover_` 前缀资源。
- `python3 tools/generate-book-cover-schema.py`：从审核后的 V10 SQL 生成语句和 SHA-256，不执行数据库操作。
- `node tools/verify-book-covers.mjs`：执行生产验证与 book CRUD 方法，核对 12×1,756 组合、资源、默认值、非法 key、持久字段、旧调用和版本冲突。
- `python3 docs/database/verify_book_covers.py`：内存数据库检查迁移保持旧资料／金额、事务回滚、非法字段、完整数据库备份、旧备份升级后 schema 一致性；包含 V9 基础回归共 10 项。

未执行原生构建、设备迁移或真机主题切换验证。配色预览为本地矢量预览，不代表原生页面截图。

书签仅标识当前正在使用的账本：列表中只为当前且未归档的账本绘制，首页当前账本显示。新账本和其他账本不显示书签；编辑当前账本时主预览显示书签；配色缩略图的书签独立表示当前所选配色，新建账本时也显示。中心图标统一为 10% 不透明度，不影响图标选择器的识别清晰度。

编辑面板改用独立半透明背景 xq_book_editor_panel，浅色 #66FFFFFF（40% 白色）、深色 #33202224（20%）；面板内容不整体降低透明度。图标选中底保留所选配色的实色 cover，44vp 图标格明确水平、垂直居中，使 24vp 图标居于底块正中；不降低图标格透明度。封面缩略图本身仍按原配色绘制。

账本选择列表按简洁布局显示封面、名称、有效交易笔数和当前勾选；使用与编辑面板相同的半透明背景，去掉正在使用／点击切换与常驻操作。编辑和归档／恢复放入长按菜单，创建入口移到列表下方，移除底部共享账户说明。归档账本单独分组，保留历史交易计数。

books() 增加只读 entryCount 字段，单次 LEFT JOIN 聚合 v_posted_transactions 中 expense／income／transfer，空账本为 0；草稿、删除和未提交导入不计，退款／报销到账不重复计数。字段只用于展示，不存储、不迁移。内存回归直接执行生产 SQL，覆盖收支转账、草稿、空账本、删除及归档。

区分选择与管理入口：首页账本名打开「选择账本」，保持简洁行及长按操作；我的页「账本管理」通过 openBookSheet(true) 打开，标题为账本管理，每行底部靠右直接显示编辑、归档／恢复按钮。半透明背景、封面、交易笔数及当前标记共用；管理状态不持久化，每次打开入口明确设置。

封面中心图标纵向位置按 (封面高度 − 图标高度) / 2 计算，即 coverWidth × (1.20 − 0.36) / 2；修正原 0.47 倍宽度定位造成的偏下。预览、列表与首页封面统一生效，不改图标尺寸或透明度。

配色选择不使用勾选图标：封面置于固定 44×48vp 的容器，当前选中配色显示书签，底部名称使用主色；未选中无书签、名称为次级文字色。名称固定 20vp 高并居中，切换不影响位置和高度。该选择状态不依赖是否正在编辑当前账本；账本列表中的书签仍仅显示于当前使用的账本。
