# 小巧记账数据库设计

日期：2026-11-02。当前处于逻辑模型评审阶段，未创建应用数据库、执行迁移或修改ArkTS、SDK、依赖与权限配置。

## 已知需求

- 鸿蒙本地记账，手机、平板和折叠屏共享业务模型；屏幕布局不进入数据库。
- 多账本；支出、收入、转账；多级分类且允许直接选父分类；多标签。
- 账户余额校准须显示独立调整记录，不伪装成收支。
- 优惠记录减免额，以实付记账；报销先支持待报销标记。
- 计入预算、计入资产；商户、地址和多张图片。
- 完整多币种：原币、账户实际结算、本位币统计、跨币种转账与历史汇率快照。
- Excel/CSV、支付宝/微信模板建议；字段映射、值匹配、预览与重复检查。
- 历史导入默认不改变余额，可按批次明确切换；后续编辑不能悄悄改变这一策略。
- 手动WebDAV完整备份恢复；华为个人云空间能力留待接入阶段核实，不按已接入设计。

## 已确认的业务规则

1. **账户与余额全局共用，账目归属不同账本。**
2. **“计入资产”控制单笔是否影响所选账户余额。** 与“计入预算”、账户级是否纳入净资产、导入余额策略相互独立。

历史导入仍默认preserve；即使计入资产为真，也不会改变余额。该策略固化到每笔交易，不能在普通编辑中静默改成apply。
