# 表单、Sheet 与子页面开发规范

2026-11-21。本文整理用户已确认的开发约定，适用于后续新增页面及本轮明确要求修改的页面。历史 Figma 稿和阶段开发记录存在差异时，以本文及用户后续明确要求为准。本次只落文档，不表示所有旧页面已经迁移或真机验收。

## 页面与 Sheet 的选择

| 场景 | 默认承载方式 |
| --- | --- |
| 独立管理、可持续浏览、多字段编辑、需要完整滚动空间 | HDS 子页面，如账本管理、汇率转换 |
| 当前任务内的选择、筛选、简短编辑 | Sheet，如选账本、选币种、手动汇率 |
| 删除等不可逆动作 | 确认对话框，明确对象、范围、后果 |
| 完成或失败的即时反馈 | 消息提示，不替代字段错误或页面错误 |

同一任务内的 Sheet 可以有内部层级；从父页直接打开编辑时不显示无意义的“返回”。已有明确承载方式的功能沿用用户决定，不为套用默认规则擅自改成另一种方式。

## 表单项的共同规则

- 标签独立显示，输入值／占位内容位于有边界的字段区域。占位文字不替代标签。标明选填、单位及必要格式，帮助文字放字段下方。
- 可输入项使用可辨识背景、浅色 1 vp 描边、12 vp 圆角；焦点描边及光标使用品牌色。不得用全透明无边框文字冒充输入框。
- 可选择项沿用同样的字段容器，右侧放 Lucide 下拉／向右箭头，整个有效行可点击。只读项无箭头、无点击反馈，用专用背景和更弱的描边，并给出锁定原因；不要仅降低整个容器透明度导致内容不可读。
- 临时禁用与业务只读语义分开：提交中防止重复操作；永久锁定的字段能看清值和锁定原因。禁用后拦截输入和选择事件，不能只改颜色。
- 默认字段最小高度 48 vp、水平内边距 14 vp；汇率等突出数字可用 56 vp；多行或大字号允许增高，不裁切文字。标签与字段间距 8 vp，同组字段间距默认 16 vp，组间 24 vp；辅助／错误信息距字段 8 vp。
- 错误贴近对应字段显示，保留已填内容；成功完成后结束忙碌态。首次无值显示“计算中…”，刷新保留旧值并显示“更新中”，失败显示原因，完成自动替换。
- 金额复用 MoneyAmountField 和自定义数字键盘；汇率复用 ExchangeRateField，不能按货币金额强制两位小数。MoneyAmountField 自身为透明输入核心，调用者应提供可辨识的字段容器；不要全局改核心破坏既有金额卡片。
- 字体使用现有 fp 规范，尺寸使用 vp；资源使用 AARRGGBB。背景透明度只作用于背景层，文字、旗帜、图标保持可读。
- 多选行采用一个切换入口；右侧“编辑”独立命中。复选图标只呈现状态，避免父子同时处理造成一次点击切换两次。选中不靠长按，不依赖无效的 ClickEvent.stopPropagation。延迟保存回写不可取消用户之后的选择。

## 普通页面中的表单

- 页面使用 xq_app_surface_page；普通卡片使用不透明 xq_app_surface_card，不沿用 Sheet 的半透明整块面板。
- 手机页面内容左右 16 vp，卡片圆角 16 vp、内部默认 16 vp；避免外层卡片、内层表单反复叠加边距。
- 分组卡片中的紧凑选择行可由卡片、分割线、当前值和箭头共同表达点击区域，不必逐行再套输入框；商户／地址／备注等直接输入项仍用独立浅底描边和焦点态。历史记账币种隐藏箭头，显示“只读”和锁定原因。
- 页面中的字段背景使用现有适用的不透明表面色，保留浅描边和明确焦点。不能为了复用汇率 Sheet 色而把整个页面卡片改成半透明。
- 记一笔页面卡片的外层上下 padding 统一为 12 vp，左右维持各卡片已有布局；多行信息卡只在整卡顶部／底部加一次，内部行距不叠加。分类网格保留自身左右布局和折叠高度，单行卡用最小高度容纳内容，不能新增 padding 后仍用旧固定高度挤压内容。
- 视觉留白必须同时检查内容行高度：记一笔币种、用途、手续费预算、预算／资产等单行卡片统一最小 56 vp（上下各 12 vp，内部内容行 32 vp），内容垂直居中；预付款／待报销等多行开关卡片的每行也采用最小 32 vp。不能仅写相同 padding 却让不同控件撑出不同视觉高度。大字号允许自然增高。整页卡片的首行标签／区块标题统一最小 32 vp 并垂直居中，包括分类、预算分类、转账账户、备注与图片附件；多行信息中的账户／时间选择行同样对齐。分类网格、输入框、多行信息及备注卡片按内容增长，不强制总高 56 vp；金额展示区保留金额所需字号和高度。
- 记一笔卡片内左侧字段／区块标签统一为 14 fp、FontWeight.Regular、xq_font_secondary，参照付款账户；字段值、金额、选中分类名称和右侧品牌色操作不套用标签样式。
- 记一笔卡片右侧橙色文字操作以“管理分类”为基准：12 fp、FontWeight.Medium、xq_font_emphasize，透明背景，按钮高 28 vp；分类管理、预算分类管理及地图选点保持一致。该规则不套用底部主操作、金额或选中项文字。
- 卡片外标题、日期及说明相对卡片边缘额外内收 8 vp；卡片宽度不缩小。详见 [布局规范](layout-tokens/README.md)。
- 大字号、窄屏及宽屏根据可用宽度布局；内容列可限宽，不能把整页强制居中成弹窗。

## Sheet 中的表单

- 采用已确认的管理币种 Sheet 布局：根容器左右 16 vp、上 20 vp、下 16 vp；表单面板内部 12 vp，因此字段总水平留白通常为 28 vp。不要再叠加一层 16／24 vp。
- 根内容、Scroll 内容与表单内容顶部对齐。短表单按内容取合理高度，不强制全屏；长列表按可用高度滚动，不能垂直居中在面板中段。
- 标题最小高度 40 vp，右侧预留系统关闭按钮 48 vp；内部下钻时用 40 vp 热区的 Lucide 左箭头（22 vp），与标题间隔 8 vp，不使用文字“返回”。直接打开的编辑只显示标题及关闭入口。
- 系统 Sheet 提供外层圆角和关闭控件，内部不再画一套整屏壳。项目当前 Sheet 圆角以 32 vp 顶部圆角为基线，底边贴屏为 0；尊重系统在不同高度和窗口下的原生形态。
- 外层优先使用系统沉浸材质（THICK、applyShadow: true），先准备材质再打开。仅在支持的 API／设备动态加载，不支持时使用主题表面色回退。默认保留系统交互弹性，不把现有 ExchangeSheetMaterial 的历史 interactive: false 写法作为新 Sheet 模板。
- Sheet 默认保留系统弹性及正常点击反馈，不统一禁用 interactive 或 stateEffect。仅存在长按操作且确认与形变／手势冲突时，才在对应面板或操作区域局部关闭，记录原因。面板形变、拖拽高度与列表边缘回弹是独立行为：列表／Scroll 保留 EdgeEffect.Spring；detents 与 dragBar 按业务高度和拖拽需求决定，不为了取消弹性而一律锁死。既有 Sheet 不在本次文档调整中批量修改。
- 底部手势区：Sheet 根内容向底部系统安全区延伸，背景连续覆盖手势条区域；移除根容器固定 bottom padding，把底部留白放到 List.contentEndOffset（基础 16 vp ＋系统手势区实际高度，px 转 vp）。每次打开读取当前窗口 TYPE_NAVIGATION_INDICATOR，读取失败回退为 0 额外高度；不要叠加原来的固定底部 padding。列表保留弹性，最后一项须能滚到手势条上方。非 List 的滚动容器采用等价末尾留白，不能直接套用 List API；旋转／窗口变化时重新读取，避免使用旧尺寸。参考 ExpenseEditor.currencyPicker／measureCurrencyBottomInset；该做法已由用户查看设备效果确认，推广到其它 Sheet 时仍检查各自键盘与安全区。
- 键盘使用既有避让机制（当前汇率 Sheet 为 TRANSLATE_AND_RESIZE），保证正在输入的字段和操作能滚动到可见范围。
- Sheet 字段使用半透明背景加浅描边，不全透明；外层面板与字段背景分层，不通过一整块灰蒙蒙的 opacity 实现。
- Sheet 搜索框沿用表单字段的半透明背景、1 vp 浅描边和 12 vp 圆角，不另叠独立沉浸光感材质；颜色使用 xq_exchange_form_field_background／xq_exchange_form_border。

## HDS 子页面的固定做法

1. 新建子页面先复制现有匹配的导航结构：分类管理 CategoryManagementPage，或 Index.bookManagementPage／ExchangeRatesPage；不是只复制截图外观。
2. 使用 HdsNavigation、Stack 模式和 MINI 标题。返回、标题、菜单走 titleBar；不手画一条固定高度标题去模拟 HDS。originalStyle 和 scrollEffectStyle 均指定适配主题的标题／图标色，divider 关闭。
3. 标题材质采用 IMMERSIVE + ADAPTIVE，滚动效果为 IMMERSIVE_GRADIENT_BLUR、enableScrollEffect: true；bindToScrollable 绑定**实际可滚动内容的同一个 Scroller**。不能只写枚举而不绑定，也不能用线性渐变假装背景模糊。
4. 沿用参考页面安全区配对：标题 enableComponentSafeArea，根视图处理顶部系统布局安全区和上下系统安全区。检查内容不会顶进状态栏，也不重复加状态栏高度或制造巨大顶部空白；不要盲目照搬固定坐标。
5. 标题栏不要随意覆盖 backgroundColor、mask 或 blurRadius，避免盖住沉浸渐变模糊。页面自身仍使用不透明页面背景，内容卡片使用实色。
6. 系统返回与左上角返回调用同一业务处理：编辑 → 列表 → 来源页；忙碌态保护、草稿保留、键盘和 Sheet 层级需同时考虑。当前项目不少子页由 Index 状态显示，并非独立路由，必须同步接入 Index.onBackPress，不能只画一个返回箭头。
7. HdsSnackBar 显示时接 pressBackCallback，关闭提示后转交当前页面返回逻辑；根页面只关闭提示，不能由提示直接退出应用。参考 Index.notify。
8. 新增子页面不新增底部主 Tab；是否显示底部操作区沿现有匹配页面规则。主要操作可固定，滚动区必须留足操作区、导航和键盘空间。
9. Sheet 的整块模糊与 HDS 子页面标题的渐变模糊是两种能力。当前自绘 Row 的 Sheet 标题没有原生独立顶部渐变模糊配置，不宣称已实现，不另造模拟层。

## 实现参照与验收边界

- 表单及 Sheet：CurrencyManagerSheet、ExchangeRateField、ExchangeRatesPage.baseSheetOptions、presentation/exchange/ExchangeSheetMaterial。
- 子页导航：CategoryManagementPage、Index.bookManagementPage；系统返回／提示：Index.onBackPress、Index.notify。
- 新页面或明确要求的改版按本规范直接实现，无需每页再次询问“是否用 HDS／是否加模糊／是否做只读态”。未授权的数据结构、公共接口、依赖、权限或配置修改仍遵守根目录 AGENTS.md 的确认要求。
- 改动后按范围执行项目现有验证。检查浅深色、字段焦点／只读／错误、键盘、列表滚动、打开关闭、标题／系统返回及异步完成；未运行设备时明确写“未进行真机视觉与交互验收”，不能用字符串检查宣称原生交互已验证。
- 不为推广规范批量重做无关页面；发现旧页面不一致先记录，待用户明确要求改动。
