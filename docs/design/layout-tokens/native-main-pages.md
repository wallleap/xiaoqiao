## 布局规则

- 390×844 标准稿，检查320宽度。左右边距16；根容器顶部16、底部28。保留模拟系统状态栏，开发不可重复叠加系统安全区。
- 页面浅灰 F1F3F5；普通卡片纯白且无描边。首页预算卡片保留原深色外观。
- 卡片内边距16；普通卡片圆角16；摘要/按钮圆角20。模块间距12/16，文字列内间距2。
- 账目、账户、分类行使用横向布局：图标固定，文字列 Fill，金额 Hug。保留现有分类图标、账户品牌图标和背景色。
- 趋势图的标题、坐标标签为独立文字布局；只有折线绘图区伸缩。分类名称、占比和金额是原生文字行，避免整体缩放文字框。
- 导航为原生横向布局，最大圆角32、高64；中央按钮保留原橙红渐变，当前页仅通过文字与图标高亮。
- 新稿导航采用不透明白底，左右约束随宽度伸缩；在当前844高画板中 y=720。实际原型发现10%白底会让下方橙红按钮透入、降低资产高亮的可读性，因此仅将三个新稿导航的白底调整为100%；用户手调的设置页与共享旧模板未修改。
- 外层「滚动视口」Width/Height Fill 且裁切，Overflow Vertical；内层「滚动内容」Width Fill、Height Hug，并保留112底部内边距。内层高度作为外层滚动范围，末项可滚到导航上方。
- 字体开发目标仍为系统默认、数字 DIN，字号使用 fp。Figma 可用字体仅作预览，本轮未添加字体依赖。

- 320与390宽度的最终截图均已检查；导航在320宽度下为288，390宽度下为358。
- 修复了早期固定宽度裁切、图形缩放造成文字换行和金额分行的问题。
- 实际进入资产页原型并滚动，新增账户按钮能完整露出，悬浮导航保持位置。

- 用户手动修改的设置样板保持原样。
- 本文记录三个手机主页面。新增的记一笔、账目详情和预算页见 [表单与票据页原生布局](native-form-pages.md)；备份恢复及多设备稿未在这轮进行原生布局重建。
- 原型验证覆盖布局、尺寸与滚动，不代表页面跳转或记账业务已经实现。
- 本轮未绑定所有 Figma Variables，也没有将所有重复行全部转为组件实例；这些行是可编辑的原生 Auto Layout。
