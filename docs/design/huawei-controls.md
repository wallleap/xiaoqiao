# 小巧记账：HDS沉浸光感控件优先规则

日期：2026-11-02。依据用户最新要求，后续UI优先使用HDS沉浸光感控件，并参考[华为控件设计规范](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/general_overview-0000001929599380)中的控件。本文是现有页面的选型约束与对应表，不代表Figma已替换为官方控件实例，也不代表开发组件已接入。

## 首页实际接入状态

2026-11-02：首页已接入 UIDesignKit 的 HdsNavigation（标题插槽、原生搜索菜单、沉浸材质）、HdsListItemCard（原生主副文字与业务图标/金额插槽）、HdsTabs（悬浮沉浸材质）及 HdsSnackBar（即时反馈）。实现和验证边界见 [首页开发说明](../development/ledger-home.md)。这不表示其他页面或全部基础控件都已完成 HDS 接入。

首页收支筛选采用现有 `@kit.ArkUI` 的 ChipGroup 单选胶囊和 IconGroupSuffix 筛选入口，遵循[子页签规范](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/chipsgroup-0000001929788350)，移除“最近账目”标题及手绘下划线选项。

## 使用顺序

**HDS沉浸光感控件 → 其他HDS控件 → ArkUI基础控件 → 必要的业务定制。** 此优先级覆盖此前泛指“官方控件优先”的表述。

- 有适用的HDS控件且支持沉浸光感时，优先复用其材质、交互和状态能力；外观按现有品牌Token及官方允许范围调整。
- 先落实导航栏和悬浮底部页签的HDS选型。其他控件是否具有沉浸光感能力需逐项核对，不能因属于HDS就标记为支持。
- 官方已介绍HDS悬浮页签与沉浸光感能力，参考[华为开发者月刊：UI Design Kit更新](https://developer.huawei.com/consumer/cn/monthly/202604)。具体支持范围、API、系统版本及设备差异仍以目标版本文档为准。
- 普通内容卡片继续沿用此前确认的纯白底、无描边或白色描边；导航与浮层等受支持区域按沉浸光感规范处理。深色预算摘要和品牌配色保持原有方向。
- Figma需区分常态预览、交互光感示意和开发标注；静态高光/模糊不能作为真实系统材质与动效已经实现的证明。

1. 先匹配官方控件的用途和交互，再用现有品牌色、文字、圆角和间距Token调整支持的外观。
2. 优先复用官方控件；业务内容不同但交互相同的场景，用系统控件组合承载。
3. 标准控件不能满足金额计算、分类网格等业务需求时，保留必要定制，并复用基础按钮、文本、列表、面板及交互状态。
4. 官方设计目录中的控件名称不等于已确认的ArkUI/HDS API。开发时需对照项目目标SDK、系统版本与官方API确认可用性；本轮不新增SDK、依赖、权限或配置。

## 页面对应

下表为小巧记账的选型决定，官方控件名称来自控件概览；具体尺寸、状态和设备差异在落稿前继续核对对应详情页。

| 场景 | 优先控件 | 应用方式 |
| --- | --- | --- |
| 页面返回、标题和右侧操作 | HDS导航（优先沉浸光感） | 统一返回、标题与操作区，减少自画导航容器；居中自定义内容需另核对实际组件能力。 |
| 账目、统计、资产、设置导航 | HDS底部页签（优先悬浮与沉浸光感） | 保留已确认的悬浮方向；中央“记一笔”是操作按钮，不赋予选中页签语义。先检查标准页签的布局能力再决定必要封装。 |
| 支出 / 收入 / 转账、统计支出 / 收入 | 子页签 | 表达内容区域切换，与标签、筛选选项区分。 |
| 周 / 月 / 年 / 自定义、Excel / CSV | 分段按钮 | 表达互斥模式或范围选择；自定义时间范围打开日期选择流程，不使用标签样式冒充导航。 |
| 账本、账户、币种、源列等简短单选 | 下拉按钮、单选框 | 选项少且简单时用标准选择；含样例、分组或长名称时放入半模态面板中的单选列表。 |
| 搜索账目、商户、分类 | 搜索框 | 统一输入、清空、取消、焦点与搜索结果行为。 |
| 备注、商户、地址、WebDAV设置 | 文本框 | 采用系统输入与校验状态，按内容区分单行、多行及密码输入。 |
| 日期、时间 | 选择器 | 优先标准日期/时间选择，不单独绘制一套滚轮或日历交互。 |
| 设置、账户、映射项、问题记录 | 列表、子标题、分隔器 | 用分组与层级组织内容；白色卡片承载列表，避免每个字段都变成独立卡片。 |
| 导出字段、记录选择、附带图片 | 勾选 | 用于可多选内容，保留选中、未选、禁用等状态。 |
| 待报销、同步功能等开关设置 | 开关 | 用于独立开启/关闭状态；涉及授权或风险的动作先完成相应确认。 |
| 预算、资产“计入 / 不计入” | 紧凑下拉按钮 | 保留此前确认的紧凑排法和信息图标，不因这次统一而擅自改回独占一行的大开关。 |
| 标签选择与移除 | 操作块 | 与子页签、分段按钮保持不同语义，必要时支持多选或移除。 |
| 多级分类、账户选择、导入余额策略 | 半模态面板＋列表/单选框 | 复用标题、遮罩、关闭、滚动与安全区规则；子分类取消仍保留父分类，余额选择取消仍保留当前策略。 |
| 删除、恢复覆盖、破坏性确认 | 弹出框 | 明确对象、后果和操作按钮；简短说明不用大弹出框。 |
| 预算/资产信息图标的简短说明 | 气泡提示 | 就近解释，不占表单一整行；内容过长再使用面板。 |
| 保存、导入、导出、编辑 | 按钮、核心操作栏 | 统一主次、禁用、加载和按压状态；品牌渐变按组件支持能力应用。 |
| 备份、导入导出进行中 | 进度条 | 可计算进度时显示真实进度；不能计算时不编造百分比。 |
| 操作结果反馈 | 即时反馈、即时操作 | 短反馈与可执行操作分开；错误详情和需要处理的问题留在页面内。 |
| 预算环与统计摘要 | 数据可视化＋业务内容 | 优先核对系统可视化能力，保留已确认的预算概览方向与准确金额语义。 |
| 分类左右滑动分页 | 导航点＋业务网格 | 保留最多两行、左右滑动及滚动后一行吸顶的业务结构；多级分类通过面板继续选择。 |

## 保留的业务定制

- 金额计算键盘：需要小数、删除、加、减、等于与保存；不是普通步进加减控件。默认显示，点击金额可再次打开，不添加冗余键盘图标。
- 分类与账户内容：继续使用现有分类资源及accounts品牌图标；交互容器优先复用列表、选择控件和面板。
- 账单详情、预算摘要、多币种金额：保留业务信息层级，底层文字、按钮、列表及可视化优先复用。
- 悬浮导航的品牌外观、中央记账操作：保留用户已确认的方向，先评估标准控件支持能力，避免仅为外观重写全部导航交互。

## 设计与开发检查

- Figma中区分“按官方规范绘制的自有图层”“官方控件实例”和“业务组合”，不能把Auto Layout图层标成已经接入的系统控件。
- 同种控件覆盖正常、选中、禁用、按压、加载、获焦、错误等适用状态；支持系统字体放大、深浅色、触控区域及无障碍语义。
- 保持浅灰页面、纯白普通卡片、已有品牌色和深色预算摘要；不以控件统一为由覆盖用户手调页面。
- 字体使用系统默认、金额数字标注DIN；开发字号使用fp，布局使用vp，沿用已保存的Token。
- 手机、折叠屏和平板按可用空间选择合适呈现；不能把手机弹出层简单等比放大，也不能未经API验证宣称能够自动适配。
- 后续Figma优化以本表为选型约束逐组执行。本轮仅核实官方目录并保存规则，未批量改动现有Figma页面或应用代码。
